Know which serializer is being tested

Ordinary pickle usually serializes functions by importable module/name, so a lambda fails. SB3 wraps environment factories in CloudpickleWrapper using cloudpickle, which supports many lambdas and closures. A lambda alone is not evidence of a Windows-fatal SubprocVecEnv defect. A captured threading.Lock can fail even with that wrapper; a named factory is not a cure for every unpicklable resource.

The unchanged PPO CLI’s integration option tests ordinary-pickle lambda failure, actual SB3 lambda factories under spawn and captured-lock serialization failure. Its recorded report says which versions/platform passed. The successful workers expose action_masks directly. Run that optional integration only when doing local library verification; this rebuild does not run its training segment.

Put process creation under if __name__=="__main__". Pass serializable configuration and construct file handles, locks and environments inside the worker that owns them. Use separate seeds and worker-local masks. Close workers in finally, propagate errors and avoid hanging on queue reads after a failed child. A process can start successfully while its environment later fails.

A complete ordinary-spawn exercise

Save the example below as an importable .py script and run it, not an interactive notebook cell. It forces spawn across platforms, creates resources in the worker, sends a result and bounds waits. Replacing the top-level factory with a local lambda tests ordinary serialization; it does not reproduce SB3’s cloudpickle route. The main guard is required even when a factory can be serialized.

import multiprocessing as mp
from queue import Empty

def make_toy():
    return {'tag': 0}

def spawn_worker(factory, queue):
    try:
        queue.put(('ok',factory()['tag']))
    except Exception as error:
        queue.put(('error',repr(error)))

def ordinary_spawn_example():
    ctx = mp.get_context('spawn')
    queue = ctx.Queue()
    worker = ctx.Process(target=spawn_worker,args=(make_toy,queue))
    started = False
    try:
        worker.start(); started = True
        status,value = queue.get(timeout=20)
        worker.join(timeout=20)
        if worker.is_alive() or worker.exitcode != 0 or status != 'ok':
            raise RuntimeError(f'worker failed: {status} {value}')
        return value
    except Empty as error:
        raise RuntimeError('worker did not return') from error
    finally:
        if started and worker.is_alive():
            worker.terminate(); worker.join(timeout=5)
        queue.close(); queue.join_thread()

if __name__ == '__main__':
    print(ordinary_spawn_example())
