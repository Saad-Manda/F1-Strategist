Why this matters

A return scores a realized sequence. Before choosing an action we instead want an expectation over the sequences that may follow. A value answers that question under a stated policy, starting state and objective.

Two actions, two future scores

Use A and B from the preceding reading. At gamma 1, DIRECT gives 3 and stops. VIA gives 1 and then FINISH at B gives 4, totaling 5. If the policy chooses each action with probability 0.5, its expected return starting at A is 0.5 × 3 + 0.5 × 5 = 4.

At gamma 0.5, DIRECT still gives 3 immediately. VIA gives 1 + 0.5 × 4 = 3. The same policy's expected return at A is now 3. A statement like “A has value four” is incomplete without the policy and discount setting.

At B the return is 4 under either setting, because FINISH's reward is immediate. The terminal state's continuation value is 0. The final reward was already returned on the transition into it.

State value and action value

Write V^π(s) = E_π[G_t | S_t = s]. V is the state value: expected return starting in state s and then following policy π. The superscript π labels the policy, not a power. The subscript on E says that action choices, as well as environment outcomes, follow the stated policy and model.

Write Q^π(s,a) = E_π[G_t | S_t = s, A_t = a]. Q is the action value: take action a first, then follow π afterward. In our world, Q^π(A,DIRECT)=3 and Q^π(A,VIA)=1+γ×4. State value averages these action values using the policy's action probabilities:

V^π(s) = Σ_(legal a) π(a|s) Q^π(s,a)

Both V and Q have the units of return. They are not success probabilities, immediate rewards or values attached only to the last observation. A value estimate stored in a table can be inaccurate; giving it the name Q does not certify its correctness.

The continuation policy matters

Our small world has no decision after reaching B, so every continuation policy must FINISH. That special case makes the action values independent of the downstream policy. In a different world, suppose B offered a choice between rewards 4 and 0. If the continuation policy always chose 0, VIA's action value at gamma 1 would be 1, not 5. Taking VIA first does not give you permission to assume perfect behavior afterward.

This is why a fixed-policy value and an optimal value generally differ. Later we will write an asterisk, as in V*, to label optimality. It is a different question: the best expected return available through permitted choices.

Common mistake: comparing an immediate reward for one action with a full return for another. Use a common objective and starting time for both.

At gamma one, does the half-DIRECT/half-VIA policy have value 5 because VIA is available?

No. It chooses DIRECT in half the runs, so its state value is 4. Five is achievable by always choosing VIA in this particular world.
