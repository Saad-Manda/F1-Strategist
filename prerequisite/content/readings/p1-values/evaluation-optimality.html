Why this matters

You can now compute a value for a given policy or choose a better legal action. The Bellman equations express these questions for every state at once. They describe what values satisfy; a solver or learning algorithm is still needed to obtain them.

Evaluate a specified policy

For a finite model, let p(s',r | s,a) be the joint probability of next state s' and reward r, given current state s and action a. The policy-evaluation equation is:

V^π(s) = Σ_(legal a) π(a|s) Σ_(s',r) p(s',r|s,a) [r + γ V^π(s')]

The inner sum averages environment outcomes after an action. The outer sum averages the policy's action choices. Terminal continuation is zero. If rewards are deterministic for each transition, one can equivalently use the transition probabilities and that reward rule.

In A/B, B has value 4 and terminal Z has value 0. At gamma 1, half-DIRECT/half-VIA gives V^π(A)=0.5×3 + 0.5×(1+4)=4. These values satisfy all three states' equations. The policy is still suboptimal at A; correctly evaluating it does not change its choices.

Ask for the best permitted policy

The asterisk labels optimal values. For the standard finite discounted MDP setting, the state-value optimality equation replaces the action average with a maximum:

V*(s) = max_(legal a) Σ_(s',r) p(s',r|s,a) [r + γ V*(s')]

The expectation over outcomes remains. Similarly, Q*(s,a) scores the first action with optimal continuation, and V*(s)=max_(legal a) Q*(s,a). In A/B at gamma 1, V*(A)=5; the evaluated mixture has value 4. Its Q^π entries happen to match Q* because B has no further choice. Do not generalize that coincidence to a larger world.

These equations assume a sufficient state, a specified reward objective and the defined legal action set. A planning algorithm that knows the model and a learning algorithm that samples experience may target the same values by different methods. A finite training budget or approximate function does not guarantee an optimal result.

For an intrinsic horizon, include time

Let h mean decisions remaining. Write V_h(s) for the corresponding value, with V_0(s)=0 at the task deadline. A backup uses the h−1 continuation, not the same h again.

With gamma 1 in A/B, one decision remaining gives DIRECT 3 versus VIA 1, so V_1(A)=3. Two remaining allow FINISH after VIA, so V_2(A)=5. This is a finite backward calculation; it does not rely on a discounted infinite-horizon contraction. Including h in state is the same information requirement identified in lesson 1.2.

Common mistake: treating a truncated collection window as this task deadline, or reading an optimality equation as evidence that an implementation has already learned its solution.

What value does an always-DIRECT policy have at A, gamma one?

Three. The optimal value five does not apply to every policy. Evaluation asks what this policy does; optimality asks the best return available.
