Track seconds, returns and optimization quantities separately

The Phase 5 plan uses negative lap time as reward, plus the environment's documented penalties or offset. At roughly 95 seconds per lap over 52 laps, a no-penalty raw return is −4940. Near the start, a gamma-one action value can have that scale; near the finish it has fewer remaining costs. An initial network near zero does not immediately get a −4940 one-step label: a frozen near-zero successor initially gives roughly the immediate reward, and long-horizon values develop through bootstrapping.

The old plan labels a large output bias the most likely explanation for flat performance. That diagnosis needs evidence. First check successor observations, masks, terminal flags, gather shapes, detached targets, finite tensors, replay coverage and whether evaluation disables exploration. Then inspect reward ranges, prediction/target ranges, gradient norms and clipping frequency. Large loss alone does not identify which contract failed.

Calculate the scale effect

Squared errors [1,−2] have MSE 2.5; [10,−20] have MSE 250. Scaling both predictions and labels by ten scales squared loss by 100 and its derivative with respect to predictions by ten. Shared-network parameter gradients also depend on the model's derivatives. Keeping learning rate and clipping fixed need not preserve the optimization path.

The planned agent uses smooth L1 with beta one: loss is 0.5e² when |e|<1 and |e|−0.5 otherwise. The corresponding prediction derivative is e in the small region and sign(e) outside. For the two error pairs, mean losses are 1 and 14.5. This bounds each output-error derivative; it does not universally bound every parameter gradient, whose chain-rule factors still matter. Gradient-norm clipping is a separate operation and does not directly cap Adam's eventual parameter change.

def smooth_l1_witness(errors):
    errors = torch.as_tensor(errors,dtype=torch.float64)
    return torch.nn.functional.smooth_l1_loss(errors,torch.zeros_like(errors),
                                              reduction="none")

assert torch.equal(smooth_l1_witness([1.,-2.]),
                   torch.tensor([0.5,1.5],dtype=torch.float64))
assert float(smooth_l1_witness([10.,-20.]).mean()) == 14.5

Reference: PyTorch SmoothL1Loss. Its beta-one formula coincides with Huber at unit threshold; other beta choices need their stated scaling. The core teaching update's huber=True switches to this loss; the standalone PER witness still uses weighted squared errors.

Center deliberately and compare physical outcomes

Adding a fixed 90-second baseline gives roughly −5 per lap and −260 over 52 laps, a +4680 shift. Under a common fixed remaining horizon H with gamma one, each action's value shifts by 90H, preserving its ranking. With discounting the common shift is 90Σ_(k=0 to H−1)γ^k. Early aborts, variable-length tasks or state/action-dependent offsets need separate analysis; a changing base_pace offset is not automatically the same fixed constant.

Centering changes target magnitudes, errors, optimizer history and priority allocations during learning. If all errors scale equally by c and raw priorities have negligible epsilon, proportional probabilities can remain unchanged, but additive epsilon and unequal errors break that simplification. Centering does not guarantee faster convergence or erase representation failures. Keep physical time and raw reward in info; evaluate all agents in those same units and settings.
