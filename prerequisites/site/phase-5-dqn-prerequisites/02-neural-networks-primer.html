Neural Networks in Four Steps

Forward pass, loss, backward pass, update: the four mechanics behind DuelingDQN.forward() and its training step, and nothing more.

Your call · from numbers to a call

The real network's output for one state is six numbers, one per call, and some calls are illegal in that state.

Which call does the agent make when it isn't exploring?

A layer as a function

A linear layer computes y = Wx + b: the input vector times a weight matrix, plus a bias vector. Stacked alone, linear layers collapse into one linear function. A nonlinearity after each one prevents that. This project uses ReLU, max(0, y), element by element. The real network's shared trunk is Linear(16→128) → ReLU → Linear(128→128) → ReLU: 16 is Phase 1's observation, and 128 is a design choice, wide enough for the function and no wider.

A forward pass by hand

Two inputs, two hidden units with ReLU, one output, no biases:

W1 = [[1.0, −1.0], x = [2.0, 1.0] [0.5, 0.5]] h_pre = W1 · x = [2.0 − 1.0, 1.0 + 0.5] = [1.0, 1.5] h = ReLU(h_pre) = [1.0, 1.5] W2 = [2.0, −1.0] y = W2 · h = 2.0(1.0) + (−1.0)(1.5) = 0.5

That is what self.trunk(x) followed by one output head does, at a size that fits on paper. Here no pre-activation was negative, so ReLU zeroed nothing.

Loss, then the backward pass

A loss turns "how wrong" into one number to make smaller. Squared error is L = (ŷ − y*)²; the real agent uses the Huber loss, for a reason page 08 gives. In DQN, ŷ = Q(s, a; θ) and y* is the TD target, so the loss measures what Phase 4's δ measured.

Backpropagation computes ∂L/∂θ for every weight by the chain rule, layer by layer from the output back. PyTorch's autograd does it for you; one weight by hand shows what it computes. With y = 0.5 and a target y* = 0:

∂L/∂y = 2(y − y*) = 1.0 ∂y/∂W2[0] = h[0] = 1.0 ∂L/∂W2[0] = 1.0 · 1.0 = 1.0

The gradient is positive: raising W2[0] would raise the loss, so a step should lower it.

Illegal calls are set to −∞ first, then the agent takes the largest output: the argmax. That is Phase 4's table rule with a network's output in place of a row of cells. Option (c) is the bug the mask exists to prevent: an untrained number for an illegal call can be the largest.

The Pit Wall shows the champion's numbers as seconds to the flag, so there the greedy call is the smallest. On lap 9 of race 29: stay out 133.32, box for A 138.62. The greedy call was to stay out, by 5.29 s, and the champion boxed.

Gradient descent: Phase 4's nudge, on every weight

The update is θ ← θ − lr · ∂L/∂θ, applied to every weight at once. It is the same idea as Phase 4's update:

Tabular (Phase 4)Function approximation
Q(s,a) ← Q(s,a) + α·δθ ← θ − lr·∂L/∂θ
One cellEvery weight
δ: how wrong this cell is∂L/∂θ: how wrong the prediction is, and each weight's part in it
α: how far one transition moves one celllr: how far one transition moves every weight

DQN is Phase 4's "nudge toward a Bellman target" with the cell replaced by a gradient step on a shared function. Pages 03 to 08 make that step trainable; none of them changes what it aims at.

Deep diveAdam, named but not derived80 words

Plain gradient descent uses one step size for every weight on every step. Adam adapts the step per weight from that weight's recent gradients, which converges faster and more reliably on noisy mini-batch gradients like this project's. It is enough to read torch.optim.Adam(self.online_net.parameters(), lr=lr) as "gradient descent with a per-weight step size", where lr is still the base step. Page 08 shows one side effect: each weight moves by roughly lr per step at most, however large its error.

Backward · three gradients and one step

Start from ∂L/∂y = 2(y − y*), then apply the chain rule as the page did.

Worked solution for the warm-up

Forward. h_pre = [1 − 3, 0.5 + 3] = [−2, 3.5]; h = [0, 3.5]; y = 0 + 0.5 × 3.5 = 1.75; L = 0.75² = 0.5625.

Backward. ∂L/∂y = 1.5. ∂L/∂W2 = 1.5 × h = [0, 5.25]. Row 0 of ∂L/∂W1 is all zero, because unit 0 is inactive and ReLU passes no gradient back through it. Row 1 is 1.5 × 0.5 × x = [0.75, 2.25].

Step. W2[1] = 0.5 − 0.525 = −0.025. The zeros are worth carrying into the code lab: a weight leaving an inactive unit gets no gradient from that example, and a unit that is inactive on every input gets none at all.
