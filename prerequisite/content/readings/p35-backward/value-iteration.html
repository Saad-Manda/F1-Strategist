A different order for a continuing task

This optional page compares backward induction with value iteration. A finite deadline gives a known zero boundary and dependencies on h−1. A continuing task may loop back to the same state, so its Bellman equation contains an unknown value on both sides. Repeated backups are one way to approach a fixed point.

Consider one state and two actions returning to it. Action LOW gives reward 1 and HIGH gives 2. With gamma 0.5, optimality says V* = max(1+0.5V*, 2+0.5V*). HIGH wins, giving V*=4. Start V=0 and repeatedly back up:

value = 0.0
trace = []
for _ in range(4):
    value = max(1 + 0.5*value, 2 + 0.5*value)
    trace.append(value)
assert trace == [2.0, 3.0, 3.5, 3.75]

Stopping is an error decision

For a finite discounted MDP with bounded rewards, the optimality operator contracts maximum value differences by gamma. If a table's maximum Bellman residual is e, its maximum error from the fixed point is at most e/(1−gamma). At gamma 0.5 a residual 0.01 bounds error by 0.02; at 0.99 the same residual allows error 1. A small update is not an identical absolute-accuracy statement across discounts.

For synchronous value iteration, calculate a new table from the previous complete table. Updating some entries in place changes the ordering into an asynchronous method; that can also be valid under appropriate conditions, but it is a different procedure. Record your update convention and stopping rule.

Why a finite race does not need this argument

At gamma one in the continuing example, no finite solution exists because rewards accumulate forever. The finite four-lap race is still valid at gamma one: its backward graph is acyclic in time. Do not infer that every gamma-one problem is invalid, or that a discounted contraction proof guarantees practical convergence of an arbitrary approximate neural learner.

Recap and self-check

Should the four-lap solver iterate until successive tables look similar?

No. Starting at the exact terminal boundary, it needs one properly ordered backward pass. Value iteration answers a different dependency structure.
