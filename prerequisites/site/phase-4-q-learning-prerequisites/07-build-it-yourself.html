Capstone brief

Six stages, two learners, one ruler

Build it in prerequisites/labs/phase4/p4_cap_toy_learners/toy_learners.py, where every stage has checks. The race is the Pit Wall's, run here without the safety car, and the ruler is the Phase 3.5 capstone's exact optimum for it, 224.49 s. Your off-policy learner is the one the Learner runs: a parity check trains both on the same random numbers and gets the same table to 1e-9. The lab block is at the end of this page.

Every name here (OffPolicyLearner, pending, run_race) is invented and matches nothing in q_learning_agent.py. As in the earlier builds, the point is to reach the real file's shape on your own, so that page 08 reads as labels for something you know.

The six stages

  1. Choose a call. explore_or_exploit is page 03's ε-greedy over the legal calls, ties to the lowest number, and decayed_epsilon its straight-line schedule.
  2. The off-policy update. Page 02's target: the lap's reward plus the best value for the next lap's legal calls, or the reward alone on the last lap.
  3. The on-policy update. Page 04's target. It needs the next call before the loop asks for it, so learn() chooses it, keeps it in self.pending, and act() hands it out next time.
  4. Forget. A reset() that clears pending, for a race that stops before its last lap.
  5. The race loop. run_race: state, legal calls, call, lap time, next state, update, five steps a lap. The learner is told −(lap time − offset), Phase 1's reward centring; the race reports the true time.
  6. Measure. No new code: train what you built and score its greedy strategy against the optimum, with no sampling noise.

A tiny world with a risky shortcut and a safe route:

Reference snippet (a last-resort hint: the lab uses a different world and different names) 
class TinyStrategyWorld:
    """
    State 0: opening decision.
      action 0 (BOX_NOW)  -> reward -12, done          (safe, known cost)
      action 1 (STRETCH)  -> reward  -1, state -> 1     (cheap now, risk later)
    State 1: reached only after STRETCH.
      action 0 (BOX)         -> reward  -8, done        (clean recovery)
      action 1 (OVERSTRETCH) -> reward -30, done        (the cliff)
    """
    N_ACTIONS = 2

    def reset(self):
        self._state = 0
        return self._state

    def legal_actions(self, state: int) -> list[int]:
        return [0, 1]   # both actions legal in both states, in this toy

    def step(self, action: int):
        if self._state == 0:
            if action == 0:
                return None, -12.0, True
            self._state = 1
            return 1, -1.0, False
        else:
            reward = -8.0 if action == 0 else -30.0
            return None, reward, True

A shared learner shell: a defaultdict table, ε-greedy over a legal list, linear decay.

Reference snippet (a last-resort hint: the lab uses a different world and different names) 
from collections import defaultdict
import numpy as np

class TDLearnerShell:
    def __init__(self, n_actions, alpha=0.5, gamma=1.0,
                 eps_start=1.0, eps_end=0.05, decay_steps=2_000):
        self.n_actions = n_actions
        self.alpha, self.gamma = alpha, gamma
        self.eps_start, self.eps_end, self.decay_steps = eps_start, eps_end, decay_steps
        self.epsilon = eps_start
        self._step = 0
        self.table = defaultdict(lambda: np.zeros(n_actions))

    def pick_action(self, state, legal, rng):
        if rng.random() < self.epsilon:
            return int(rng.choice(legal))
        q = self.table[state].copy()
        mask = np.full(self.n_actions, -np.inf)
        mask[legal] = 0
        return int(np.argmax(q + mask))

    def decay(self):
        self._step += 1
        step_size = (self.eps_start - self.eps_end) / self.decay_steps
        self.epsilon = max(self.eps_end, self.epsilon - step_size)

The off-policy learner, page 02's target:

Reference snippet (a last-resort hint: the lab uses a different world and different names) 
class OffPolicyLearner(TDLearnerShell):
    def learn(self, state, action, reward, next_state, done, legal_next, rng):
        if done:
            target = reward
        else:
            q_next = self.table[next_state].copy()
            mask = np.full(self.n_actions, -np.inf)
            mask[legal_next] = 0
            target = reward + self.gamma * np.max(q_next + mask)
        td_error = target - self.table[state][action]
        self.table[state][action] += self.alpha * td_error
        self.decay()

The on-policy learner, page 04's target, with the pre-commit:

Reference snippet (a last-resort hint: the lab uses a different world and different names) 
class OnPolicyLearner(TDLearnerShell):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self._pending_action = None

    def pick_action(self, state, legal, rng):
        if self._pending_action is not None:
            action, self._pending_action = self._pending_action, None
            return action
        return super().pick_action(state, legal, rng)

    def learn(self, state, action, reward, next_state, done, legal_next, rng):
        if done:
            target = reward
        else:
            self._pending_action = super().pick_action(next_state, legal_next, rng)
            target = reward + self.gamma * self.table[next_state][self._pending_action]
        td_error = target - self.table[state][action]
        self.table[state][action] += self.alpha * td_error
        self.decay()

Reference snippet (a last-resort hint: the lab uses a different world and different names) 
def run_episodes(learner, world, n_episodes, seed):
    rng = np.random.default_rng(seed)
    for _ in range(n_episodes):
        state = world.reset()
        done = False
        while not done:
            legal = world.legal_actions(state)
            action = learner.pick_action(state, legal, rng)
            next_state, reward, done = world.step(action)
            legal_next = [] if done else world.legal_actions(next_state)
            learner.learn(state, action, reward, next_state, done, legal_next, rng)
            state = next_state

off_policy = OffPolicyLearner(TinyStrategyWorld.N_ACTIONS)
on_policy  = OnPolicyLearner(TinyStrategyWorld.N_ACTIONS)
world = TinyStrategyWorld()

run_episodes(off_policy, world, n_episodes=3000, seed=0)
run_episodes(on_policy,  world, n_episodes=3000, seed=0)

print("Off-policy Q(state 0):", off_policy.table[0])
print("On-policy  Q(state 0):", on_policy.table[0])
print("Off-policy prefers:", "STRETCH" if np.argmax(off_policy.table[0]) else "BOX_NOW")
print("On-policy  prefers:", "STRETCH" if np.argmax(on_policy.table[0]) else "BOX_NOW")

The off-policy learner's Q(0, STRETCH) settles on −9 and stays: its target ignores the 5% of the time exploration picks OVERSTRETCH. The on-policy value is pulled below −9 each time its own exploring finds the cliff. At α = 0.5 the cell jumps most of the way to each new target, so a print shows mostly the last episode or two: usually −9, now and then −14.5. With α = 0.05 it settles between about −9.1 and −9.4, the average its exploring earns. In this toy the difference is too small to change the preferred call; lab p4-04 runs the comparison where it does.

The leak. A loop where every episode reaches its terminal step never triggers it: the last update has done = True and commits to nothing. So cut every episode off after one step, as a step limit or an exception would:

Reference snippet (a last-resort hint: the lab uses a different world and different names) 
# A step limit of 1: every episode is cut off after its first step, finished or not.
rng = np.random.default_rng(1)
leaky = OnPolicyLearner(TinyStrategyWorld.N_ACTIONS)
stale = 0
for ep in range(500):
    state = world.reset()
    if leaky._pending_action is not None:
        stale += 1          # an action chosen for state 1 is about to be used at state 0
    action = leaky.pick_action(state, world.legal_actions(state), rng)
    next_state, reward, done = world.step(action)
    legal_next = [] if done else world.legal_actions(next_state)
    leaky.learn(state, action, reward, next_state, done, legal_next, rng)
print(stale, "of 500 episodes began with a leftover action")

It prints 259 of 500. Whenever the first step was STRETCH, learn() committed to a call for state 1, the episode was dropped, and the next episode's opening move at state 0 was that leftover. Here the two states share call numbers, so nothing crashes; in the real environment the leftover would be applied to the first lap of a different race, perhaps where it isn't even legal. A reset() that clears the pending call, run at the top of every episode, brings the count to 0.

Hint 2

Stage 1: max(legal, key=lambda a: (values[a], -a)) is the best legal action with ties going to the lowest number. Stage 2: the target is reward + max(self.table[next_state][a] for a in legal_next), or the reward alone when done. Stage 3: in learn(), self.pending = super().act(next_state, legal_next) and the target uses self.table[next_state][self.pending]; in act(), hand the pending action out and clear it. Use super().act so the pending check is not triggered while choosing.
