Page 09 / 12 — Building it yourself

Build It Yourself: Toy REINFORCE, Then Toy PPO

Five stages: plain REINFORCE, adding a critic and advantage, a deliberate destructive update, PPO's clip fixing it on the same loop, and a from-scratch repro of the pickling bug.

Every name below (ToyChooser, bandit_reward, and so on) is invented for this page and deliberately does not match PPOAgent, MaskablePPO, or anything in sb3_wrapper.py. As with every toy build in this project's prerequisite sets, the point is to arrive at the same shape of solution independently, so the real code on page 11 reads as familiar structure rather than new material.

Stage 0 — a tiny noisy bandit and a softmax policy

A single-state, 2-action toy directly reusing page 01's softmax-gradient example, but with noisy rewards instead of a single fixed return per action — noise is what actually makes REINFORCE's variance problem visible:

import numpy as np

ACTIONS = ["R", "P"]

def bandit_reward(action, rng):
    """R has higher expected reward but high noise; P is lower-mean, low-noise."""
    if action == "R":
        return rng.normal(loc=1.0, scale=2.0)
    return rng.normal(loc=0.0, scale=0.5)

class ToyChooser:
    """A 2-action softmax policy over two logits, updated by a policy gradient."""
    def __init__(self, seed=0):
        self.logits = {"R": 0.0, "P": 0.0}
        self.rng = np.random.default_rng(seed)

    def probs(self):
        z = np.array([self.logits["R"], self.logits["P"]])
        p = np.exp(z - z.max())
        return {a: v for a, v in zip(ACTIONS, p / p.sum())}

    def act(self):
        p = self.probs()
        return self.rng.choice(ACTIONS, p=[p["R"], p["P"]])

    def log_grad(self, action):
        """Page 01's softmax log-gradient: d log pi(a)/d z_b."""
        p = self.probs()
        grad = {b: (1 - p[b] if b == action else -p[b]) for b in ACTIONS}
        return grad, p

Stage 1 — plain REINFORCE: update directly on the raw sampled reward

def train_reinforce(n_episodes=500, alpha=0.05, seed=1):
    agent = ToyChooser(seed=seed)
    rng = np.random.default_rng(seed + 1)
    history = []
    for ep in range(n_episodes):
        action = agent.act()
        reward = bandit_reward(action, rng)
        grad, _ = agent.log_grad(action)
        for b in ACTIONS:
            agent.logits[b] += alpha * reward * grad[b]     # page 01's update, raw G
        history.append(dict(agent.logits))
    return agent, history

# Plot history's P(R) over episodes: it should trend toward preferring R
# (the higher-mean action) but visibly jitter around a lot along the way --
# R's own noise (std=2.0) is directly injected into every single update,
# exactly page 01's stated limitation, now something you can watch happen.

Stage 2 — add a critic (an exponential moving average) and use the advantage

def train_actor_critic(n_episodes=500, alpha=0.05, critic_lr=0.1, seed=1):
    agent = ToyChooser(seed=seed)
    rng = np.random.default_rng(seed + 1)
    baseline = 0.0                      # the "critic" -- trivial here: one state, so V(s) is one scalar
    history, baselines = [], []
    for ep in range(n_episodes):
        action = agent.act()
        reward = bandit_reward(action, rng)
        advantage = reward - baseline    # page 02's A(s,a) = reward - V(s), V estimated by an EMA
        grad, _ = agent.log_grad(action)
        for b in ACTIONS:
            agent.logits[b] += alpha * advantage * grad[b]
        baseline += critic_lr * (reward - baseline)   # critic's own TD-style update
        history.append(dict(agent.logits))
        baselines.append(baseline)
    return agent, history, baselines

# Compare this run's history against stage 1's, over the same 500 episodes:
# the trajectory of P(R) should settle toward its final value with visibly
# less episode-to-episode jitter -- the variance-reduction claim from page 02,
# confirmed by a plot you produced rather than taken on faith.

Stage 3 — catch the collapse: a deliberate destructive update

Reproduce page 04's motivating problem directly: take Stage 2's loop, run it for a while, then apply one artificially inflated update following an unusually large sampled reward:

agent, history, baselines = train_actor_critic(n_episodes=200, seed=2)

# Force one destructively large update: an inflated "alpha" applied to a
# single, unusually high reward sample for whichever action is CURRENTLY
# the less-preferred one under the policy's own probabilities.
rng = np.random.default_rng(999)
probs_before = agent.probs()
under_preferred = min(probs_before, key=probs_before.get)
huge_reward = 8.0                       # an outlier draw, well above bandit_reward's usual range
grad, _ = agent.log_grad(under_preferred)
BLOWUP_ALPHA = 2.0                      # 40x stage 2's alpha
for b in ACTIONS:
    agent.logits[b] += BLOWUP_ALPHA * (huge_reward - baselines[-1]) * grad[b]
probs_after = agent.probs()

print("before:", probs_before, " after one destructive update:", probs_after)
# probs_after should show the policy has swung hard toward the action that
# was previously LESS preferred -- a single outlier update overriding
# everything learned in the preceding 200 episodes. This is the collapse
# page 04 describes, produced on purpose so stage 4 has something to fix.

Stage 4 — add PPO's clip on top of the exact same update

Reuse Stage 3's identical scenario (the same outlier reward, the same starting policy), but replace the one-shot update with a small number of clipped-objective gradient steps against a fixed "old" policy snapshot — the reader's own version of page 06's n_epochs reuse and page 04's clip, combined:

def clipped_update(agent, action, reward, baseline, old_probs, epsilon=0.2, n_epochs=20, step=0.1):
    advantage = reward - baseline
    for _ in range(n_epochs):
        grad, probs = agent.log_grad(action)
        ratio = probs[action] / old_probs[action]
        clipped_ratio = min(max(ratio, 1 - epsilon), 1 + epsilon)
        # page 04's min(): pick whichever surrogate term is smaller
        surrogate_unclipped = ratio * advantage
        surrogate_clipped = clipped_ratio * advantage
        using_clipped = surrogate_clipped < surrogate_unclipped
        effective_ratio = clipped_ratio if using_clipped else ratio
        # gradient step scaled by how far the (possibly clipped) ratio has
        # allowed the update to move, times the log-gradient direction
        for b in ACTIONS:
            agent.logits[b] += step * effective_ratio * advantage * grad[b] / max(ratio, 1e-8)
    return agent

agent2, history2, baselines2 = train_actor_critic(n_episodes=200, seed=2)   # identical seed to stage 3
probs_before2 = agent2.probs()
old_probs = dict(probs_before2)     # the "pi_theta_old" snapshot, frozen before any of these steps
under_preferred2 = min(probs_before2, key=probs_before2.get)
clipped_update(agent2, under_preferred2, reward=8.0, baseline=baselines2[-1], old_probs=old_probs)
probs_after2 = agent2.probs()

print("before:", probs_before2, " after clipped update:", probs_after2)
# Compare directly against stage 3's probs_after: this run's swing toward
# the under-preferred action should be visibly SMALLER and bounded, even
# though it saw the exact same outlier reward -- the clip stopped the
# surrogate objective from rewarding the ratio moving arbitrarily far,
# exactly page 04's argument, now demonstrated on a collapse you triggered
# yourself in stage 3.

Stage 5 — reproduce the pickling bug from scratch

A minimal, from-scratch repro of page 07's lesson — no SB3 import, own names throughout:

# toy_vec_bug.py
import multiprocessing as mp

class TinyToyEnv:
    def __init__(self, tag):
        self.tag = tag
    def step(self):
        return f"stepped env {self.tag}"

def _broken_worker(make_env_fn, q):
    env = make_env_fn()
    q.put(env.step())

if __name__ == "__main__":
    q = mp.Queue()
    # This lambda cannot be pickled once mp's start method is "spawn" --
    # which is the ONLY start method available on Windows.
    make_env = lambda: TinyToyEnv(tag=0)          # noqa: reproduces page 07 on purpose
    p = mp.Process(target=_broken_worker, args=(make_env, q))
    p.start()          # raises PicklingError here on Windows
    p.join()
# fixed_vec.py -- the page 07 fix: a module-level named function instead
def _make_env():
    return TinyToyEnv(tag=0)

if __name__ == "__main__":
    q = mp.Queue()
    p = mp.Process(target=_broken_worker, args=(_make_env, q))
    p.start()          # works: _make_env has a name mp can look up after spawning
    p.join()
    print(q.get())

Run the first script on whatever OS you have — on Windows it fails immediately with a pickling error naming the lambda; on Linux's default fork start method it may well succeed, silently hiding the exact bug page 07 describes. Run the second script and confirm it completes and prints the worker's result — the same fix applies verbatim to make_vec_masked_envs's real lambda e: e.action_masks().
