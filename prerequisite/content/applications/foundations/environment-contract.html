Transfer the loop to one racing decision

The chain had two actions and one position. The Phase 1 project specification has six actions and a 16-feature observation. The same separation still applies: a policy chooses an action from information it can see; the environment computes the cost and next observation. These readings prepare you to implement the project plan, phase-1-gym-environment.md. The examples are teaching models, not evidence that production code already satisfies the specification.

One decision completes one lap. At reset, select a scenario and starting compound, initialize counters and seed the environment's random generator. Return an observation and diagnostic information. At step, time the current lap, charge any pit loss, update the tyres and counters, then return the next observation, reward, termination, truncation and information.

The observation is an interface, not a proof of full state

IndexFeature and encoding
0Laps remaining / race length
1–5Compound one-hot: SOFT, MEDIUM, HARD, INTERMEDIATE, WET
6Tyre age / 50, capped at 1
7–9Weather one-hot: DRY, DAMP, WET
10Track temperature: (temperature − 15) / 50, bounded to [0, 1]
11Safety car active, 0 or 1

15Mandatory pit still needed, derived from usage and the rule's applicability
import numpy as np
from gymnasium import spaces
observation_space = spaces.Box(0.0, 1.0, shape=(16,), dtype=np.float32)
action_space = spaces.Discrete(6)

A one-hot encoding has one 1 and the remaining entries 0. Unlike an integer compound label, it does not imply HARD is twice MEDIUM. Space membership checks shape, type and bounds; it does not check one-hot sums or meaningful combinations. Add semantic tests too.

This vector is an observation. If a hidden historical weather scenario or an unobserved safety-car duration influences the next lap, identical vectors can have different future distributions. A complete simulator state can include that hidden process; it must not be leaked to the policy as future knowledge. Either justify sufficiency for your chosen transition model or acknowledge partial observability. Clamping ages also merges distinct ages above 50: it cannot establish the Markov property when their costs still differ.

Six actions, with a shared legal mask

Use integer labels 0 for STAY_OUT, 1 for PIT_SOFT, 2 for PIT_MEDIUM, 3 for PIT_HARD, 4 for PIT_INTERMEDIATE and 5 for PIT_WET. Discrete(6) accepts all six; legality changes with state. The project's proposed action_masks() adapter returns six booleans and delegates to one shared compute_action_mask function used by both environment and future planner. Gymnasium does not automatically enforce that adapter.

  1. Slicks are eligible in DRY or DAMP.
  2. INTERMEDIATE is eligible in DAMP or WET.
  3. WET is eligible in WET.
  4. Pitting for the currently fitted compound is masked.
  5. With only two laps left and the two-dry-compound requirement unsatisfied, mask STAY_OUT; the project's declared-wet exception disables this requirement.

These are the project's simplified simulation rules. Confirm its chosen rule version when implementing. In a dry MEDIUM state with two laps remaining and only MEDIUM used, the mask is [False, True, False, True, False, False]. Earlier in the race its STAY_OUT entry is True. Check that every reachable nonterminal state retains a legal action and that allowed actions actually satisfy the obligation; merely masking STAY_OUT is not a general proof for every possible bookkeeping convention. A −500 terminal backstop for violating the compound requirement remains independently tested. A penalty is not a substitute for filtering illegal actions.

Gymnasium's Taxi masking tutorial illustrates masks in info; a project-specific method is another interface choice. A consumer must deliberately read and apply whichever contract you choose.

A complete pit trace, with the clock convention explicit

Consider a 52-lap race with 22 laps remaining before this decision, MEDIUM age 14, dry conditions, 42°C, no safety car, and only MEDIUM used. Count remaining laps inclusively, so the next observation has 21 left. This avoids mixing a “lap 30” label with a different fuel/count convention.

Using illustrative calibrated-scale constants, current lap time is 92 + 0 + 14×0.03 + 22×1.6×0.033 = 93.5816 seconds. The terms are base pace, compound offset, wear and fuel. Age 14 is below the MEDIUM cliff at 18; there is no warmup or weather mismatch. PIT_HARD adds 22 seconds: 115.5816, giving reward −115.5816 before any centering.

Time the lap on MEDIUM before switching. Next fit HARD at age 1: its out-lap warmup belongs to the next step. Update usage to MEDIUM and HARD, clear the obligation, advance the counter, and build a fresh array:

before = np.array([22/52, 0,1,0,0,0, 14/50,
                   1,0,0, (42-15)/50, 0, 0,1,0, 1], dtype=np.float32)
after = np.array([21/52, 0,0,1,0,0, 1/50,
                  1,0,0, (42-15)/50, 0, 0,1,1, 0], dtype=np.float32)
assert observation_space.contains(before)
assert observation_space.contains(after)
lap_time = 92 + 14*0.03 + 22*1.6*0.033 + 22
assert abs(lap_time - 115.5816) < 1e-10

The result has terminated=False and truncated=False. Natural completion after the last lap is termination; an external TimeLimit can truncate an unfinished race. Preserve the distinction even if both flags can be true on one boundary.

Diagnostics and reproducibility are public contracts

Keep info["lap_time"] in physical, uncentered seconds. Specify whether lap means the completed lap or the next lap; the original project interface uses the next lap. Preserve exact spellings such as tire_age, compound, compounds_used and two_compound_rule_met. Consumers should not silently treat a missing field as zero. Return fresh dictionaries/lists so an old transition record cannot change when the next lap runs.

Call super().reset(seed=seed) and use self.np_random for scenario and hazard draws. Equal seeds plus equal actions reproduce a trajectory under the same model. Different seeds may coincidentally produce equal trajectories. Starting-compound options and later curriculum sampling belong to a documented reset contract, rather than hidden policy-dependent resets.

Recap and self-check

Observations describe available information; masks describe eligible actions; the returned reward describes the lap just completed. The new compound describes the coming lap.

Would fitting HARD before computing the pit lap be equivalent?

No. It would replace MEDIUM's current wear and pace, and could move or erase warmup. The trace would grant advantages that the specified transition does not permit.
