Trace one full rollout-update cycle

Collect [T,N_envs] rewards, flags, old values and selected logs plus observations/actions/legal masks. Compute GAE per worker with final-observation bootstrap and separate trace boundaries. Freeze advantages and return targets, flatten to B=T×N_envs samples, shuffle aligned indices, then reevaluate current actor logs and critic predictions on minibatches across epochs.

With T=256 and N_envs=4, B=1024. Batch size 64 gives 16 minibatches per epoch; ten epochs give 160 optimizer steps per rollout. Each example is revisited once per epoch, unless early stopping changes the schedule. This is current-rollout reuse, not an indefinitely retained DQN replay buffer.

A minimal combined descent loss is L_actor+c_v mean((V_current−R_fixed)²)−c_H mean(H_current). Categorical entropy H=−Σ_legal π logπ favors spread when its coefficient is positive. Illegal zero-probability entries need a safe entropy computation rather than 0×−infinity. The value coefficient, entropy coefficient, advantage normalization, critic clipping and gradient cap are implementation choices beyond the clipped actor equation.

Verify each gradient path independently

The pack tests frozen independent logs, loss signs, branch gradients, overflow rejection and diagnostics; it is not a full PPO trainer. Current actor/critic outputs receive gradients, old logs/values, masks, advantages and targets do not. For a shared trunk deliberately combine losses; for separate models verify no cross-head leak. Reject malformed singleton axes and keep minibatch alignment.

After optimization discard this rollout for the next on-policy collection. Do not update old likelihoods inside epochs.
