Phase 1 · Case brief

The 5,000-second head start

Phase 1 builds the race that every later agent learns in. Before anything else, you call one.

You are on the pit wall for a 20-lap race. Every lap you make one call: stay out, or box for a fresh set of tyres. Get to the flag in as little time as you can. At the end you see your time against an oracle that played the same race perfectly on average.

When you reach the flag, open This race as an MDP under the result. Each lap has a reward: minus the lap time. Look at the last number in the sum column. For a 20-lap race on this track it lands near −230 (the best strategy averages −231.92). The real project's race is 52 laps of 93 to 97 seconds, so the same sum comes to about −5,000.

Case 1 · open

Why does the learner start out 5,000 seconds wrong?

A learning agent keeps a guess of how good each situation is. Before it has seen a lap, every guess is 0. The true answer for the start of the real race is about −5,000. So the agent begins wrong by 5,000 seconds in the one place it starts from. Is that a problem? Is it a bug in the plan's reward? Can you fix it without changing a single pit stop the agent should make?

You will collect the evidence one page at a time:

  1. The loop: what the agent is told each lap, and what it never is.
  2. The state: what the call depends on, and why the rewards add up to the race time.
  3. The value: what the start of a race is worth, and the one change that removes the head start. The maths of the case closes here.
  4. The contract: where the reward is computed in code, and who greys out an illegal call.
  5. The build: you write the race the Pit Wall runs, stage by stage.
  6. Back to the plan: the real reward line, and what to do about it. The case closes.

Why a race is a learning problem

A strategist makes a chain of calls under uncertainty: the safety car, the weather, the tyres falling away. Each call changes the next one. Box now and you have fresh tyres for the next ten laps; stay out and the next lap is slower but the stop is still to come. A classifier that labels one lap at a time cannot see that. Reinforcement learning is built for it: an agent watches a state, picks an action, and gets a reward, and it learns to make the total as large as possible.

What Phase 1 does and does not do

Phase 1 builds the environment, f1_strategy_env.py. It trains no agent. So this set teaches two things in depth: the maths of what an environment is (an MDP) and the software contract it must meet (Gymnasium). Training (Phases 4, 5 and 9) is not covered here, even in preview. A mistake in Phase 1, such as a wrong reward, a leaky observation or a masking bug, quietly corrupts every phase after it.
