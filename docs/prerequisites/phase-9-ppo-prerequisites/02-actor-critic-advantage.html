Page 02 / 12 — A little math

Actor-Critic and the Advantage Function

Fixing REINFORCE's variance problem without changing what its gradient estimator is aiming at.

Baselines don't change the target, only the noise

Page 01 ended with a real limitation: the raw return G in ∇_θ log π_θ(a|s) · G is a noisy training signal. The general fix: subtract any state-dependent baseline b(s) from G before scaling the log-gradient by it. This doesn't change the expected gradient at all — the correction term itself has expectation exactly zero:

E_a~π[ ∇_θ log π_θ(a|s) · b(s) ] = b(s) · E_a~π[ ∇_θ log π_θ(a|s) ] = b(s) · ∇_θ Σ_a π_θ(a|s) = b(s) · ∇_θ (1) = 0

The middle step uses the same log-derivative identity as page 01 in reverse (∇_θ log π · π = ∇_θ π), and the last step uses the fact that a probability distribution always sums to 1 regardless of θ, so its gradient is exactly zero. Because b(s) doesn't depend on which action was sampled, subtracting it changes nothing about where the gradient points on average — only how much it varies from one sampled trajectory to the next, and a well-chosen baseline can cut that variance sharply.

The natural baseline: the state-value function

The obvious choice of b(s) is V(s) — "how good is this state on average, regardless of which action gets taken from here." This is a second function that has to be learned alongside the policy: the critic. The policy being improved is the actor. The critic is trained with the same TD/Bellman machinery already assumed as background from Phase 4/5 — bootstrapped value learning — just repurposed here as a variance-reduction tool for a policy gradient, rather than as the thing an agent acts on directly by taking its argmax.

The advantage function

Subtracting V(s) from Q(s,a) (rather than from the sampled return directly) gives exactly idea.md's stated concept:

A(s,a) = Q(s,a) − V(s)

"How much better was taking action a in state s, compared to the state's own average outcome." Substituting the advantage in for the raw return in page 01's gradient gives the actor-critic policy gradient:

∇_θ J(θ) = E_π [ ∇_θ log π_θ(a|s) · A(s,a) ]

The intuition sharpens directly: push up the log-probability of actions with positive advantage (better than average for that state), push down actions with negative advantage — rather than chasing the raw, noisy magnitude of G, which says nothing on its own about whether a given action was actually a good choice relative to the alternatives available in that state.

A hand-worked comparison: advantage vs. raw return

Two trajectories pass through the same state s. In the first, action a1 is taken and the episode returns G = 8. In the second, action a2 is taken and the episode returns G = 2. Suppose the critic has learned V(s) = 5.

Raw-return update (page 01): a1: push log π(a1|s) up, scaled by G = +8 (positive push) a2: push log π(a2|s) up, scaled by G = +2 (also a positive push — just smaller) Advantage update (this page): A(s,a1) = 8 − 5 = +3 → push log π(a1|s) UP A(s,a2) = 2 − 5 = −3 → push log π(a2|s) DOWN

The raw-return version pushes both actions' probabilities up — it never actually says a2 was a comparatively bad choice for this state, only that it was somewhat less good than a1. The advantage version correctly identifies that a2 underperformed this state's average and pushes its probability down, a qualitatively sharper and more useful training signal than a magnitude difference in an all-positive update.

What's still missing

Nothing here has said how to estimate Q(s,a) (or the advantage directly) from a single rollout — only that doing so beats using the raw return. There's more than one way to estimate it, and the choice trades off bias against variance exactly like Phase 4/5's n-step-vs-Monte-Carlo TD tradeoff (assumed background) generalizes.
