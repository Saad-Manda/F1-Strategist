Execute three shape-safe contracts

The pack functions accept nonempty finite vectors with matching [B] shapes. advantages returns detached returns−values. actor_loss is −mean(log_probs×detached_advantage). critic_loss is mean((values−detached_targets)²). Freeze sample weights and targets while allowing gradients through current actor logs and current critic predictions.

Take log probabilities [ln(.5),ln(.5)], values [5,5], returns [8,2]. Advantages are [3,−3], actor scalar loss is zero and critic loss is 9. Zero actor loss does not imply zero gradient with respect to the two log probabilities: it is [−1.5,+1.5]. Critic value gradients are [−3,+3]. When both samples share one policy state, chain-rule contributions combine through that shared policy.

Backward on actor loss alone must leave independent critic parameters and target/return leaves without gradients. Backward on critic loss updates values only. A shared-trunk model intentionally receives the sum of actor and critic paths to the trunk. Check that separately from target leakage.

Loss scale and normalization are choices

Squared critic loss here has no factor one-half. A library’s coefficient can change its scale. Advantage normalization may improve optimization but is optional and not part of the action-independent baseline proof. State where it occurs, which batch is normalized and how singleton or zero-variance batches are handled.

def vectors(*xs):
    if not xs or any(x.ndim != 1 or not x.numel() or x.shape != xs[0].shape or not torch.isfinite(x).all() for x in xs):
        raise ValueError('matching nonempty finite vectors required')

def advantages(returns, values):
    vectors(returns,values)
    return (returns-values).detach()

def actor_loss(log_probs, advantage):
    vectors(log_probs,advantage)
    return -(log_probs*advantage.detach()).mean()

def critic_loss(values, targets):
    vectors(values,targets)
    return ((values-targets.detach())**2).mean()

Can zero mean actor loss still have a nonzero gradient?

Yes. Opposite numerical terms can cancel while their derivatives flow through different selected log probabilities.
