Stage 1: a policy over the legal calls only

One row of three logits per state; a softmax over the legal calls, which is what MaskablePPO does with its −1e8 logits. Write masked_probs and log_grad, page 01's log-gradient with zeros on illegal calls; the check compares it with finite differences.

Reference snippet (a last-resort hint: try the stage first) 
def masked_probs(logits, mask):
    z = np.where(mask, logits, -np.inf)
    z = z - z[mask].max()
    p = np.exp(z)
    return p / p.sum()

def log_grad(logits, mask, action):
    g = -masked_probs(logits, mask)
    g[action] += 1.0
    return np.where(mask, g, 0.0)

for t in reversed(range(len(rewards))):
    delta = rewards[t] + gamma * values[t + 1] - values[t]
    run = delta + gamma * lam * run
    adv[t] = run

Stage 5: the clip, and what it doesn't do

One step on page 04's objective for one sample: ratio · A · ∇log π while the unclipped term is the smaller, zero once the clip binds. Repeat stage 4 with twenty clipped steps per lap: the policy stays where it was. But the largest ratio reached is 4.95, far past 1.2. You build a policy-gradient learner for the toy race in seven checked stages: a table policy over the legal actions, REINFORCE, GAE and a critic, one destructive update, the clip that prevents it, a small PPO, and the clip's real job when each batch is reused ten times.
