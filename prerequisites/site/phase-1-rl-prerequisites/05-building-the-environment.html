Your call · Stage 6, before you write it

Lap 13, never stopped: your A tyres are 13 laps old, far past their cliff. You box for B. In step(), you switch the tyre first and time the lap second.

Compared with timing the lap first, what happens to the cost of that pit lap?

Stage 1 — one compound, the GridWorld way

Start from the shape page 04 used: constants and spaces, then reset() with a _get_obs() helper, then step() split into two halves.

Constants and the class shell:

Reference snippet (a last-resort hint: the lab uses different numbers) 
import numpy as np
import gymnasium as gym
from gymnasium import spaces

STAY_OUT, PIT = 0, 1
HORIZON = 10
PIT_LOSS = 2.0

class ToyRaceEnv(gym.Env):
    metadata = {"render_modes": []}

    def __init__(self):
        super().__init__()
        # obs = [tyre_age_normalized] -- one feature, in [0, 1]
        self.observation_space = spaces.Box(low=0.0, high=1.0, shape=(1,), dtype=np.float32)
        self.action_space = spaces.Discrete(2)   # STAY_OUT | PIT

reset() and its _get_obs() helper : the same pattern as GridWorld, for the same reason. One place builds the observation.

Reference snippet (a last-resort hint: the lab uses different numbers) 
    def reset(self, seed=None, options=None):
        super().reset(seed=seed)
        self._lap = 1
        self._age = 1
        return self._get_obs(), {}

    def _get_obs(self):
        return np.array([min(self._age / HORIZON, 1.0)], dtype=np.float32)

step(), the timing half first. Compute this lap's time from the current tyre age, before the action changes anything:

Reference snippet (a last-resort hint: the lab uses different numbers) 
    def step(self, action):
        assert self.action_space.contains(action)
        lap_time = 1.0 + 0.05 * (self._age ** 2)   # quadratic wear
        if action == PIT:
            lap_time += PIT_LOSS

Then the bookkeeping half: apply the action, advance the lap, return.

Reference snippet (a last-resort hint: the lab uses different numbers) 
        if action == PIT:
            self._age = 0
        self._age += 1
        self._lap += 1

        reward = -lap_time
        terminated = self._lap > HORIZON
        info = {"lap_time": lap_time, "age": self._age}
        return self._get_obs(), reward, terminated, False, info

Assemble those four pieces under class ToyRaceEnv(gym.Env): in order, add a small if __name__ == "__main__": driver like page 04's (reset, loop step() for HORIZON laps, print each lap's reward), and run it. Everything from here modifies this skeleton.

Stage 2 — two tyres: pace against life

A grippier compound is faster when fresh and wears out sooner; a harder one is slower and lasts. Without that trade-off, "which tyre" is not a decision. On the Pit Wall, B is 0.6 s a lap slower than A and wears at less than half the rate.

First the data and two pure functions, no class changes yet:

Reference snippet (a last-resort hint: the lab uses different numbers) 
# Each compound: (pace_penalty, wear_rate). A is faster but wears quicker than B.
COMPOUNDS = {
    "A": {"pace": 0.0, "wear_rate": 0.09},
    "B": {"pace": 0.6, "wear_rate": 0.03},
}

def toy_pace(compound: str) -> float:
    """Fixed pace penalty of a compound relative to the fastest one."""
    return COMPOUNDS[compound]["pace"]

def toy_wear(compound: str, age: int) -> float:
    """Quadratic wear, rate depends on which compound is fitted."""
    return COMPOUNDS[compound]["wear_rate"] * (age ** 2)

Then the three places ToyRaceEnv changes. The observation grows by two (a one-hot for the fitted compound), and the action space by one (PIT_A and PIT_B instead of one PIT):

Reference snippet (a last-resort hint: the lab uses different numbers) 
STAY_OUT, PIT_A, PIT_B = 0, 1, 2

    def __init__(self):
        super().__init__()
        # obs = [tyre_age_norm, compound_is_A, compound_is_B]
        self.observation_space = spaces.Box(low=0.0, high=1.0, shape=(3,), dtype=np.float32)
        self.action_space = spaces.Discrete(3)

_get_obs() needs to report which compound is fitted, alongside the age it already tracked:

Reference snippet (a last-resort hint: the lab uses different numbers) 
    def _get_obs(self):
        onehot = [1.0, 0.0] if self._compound == "A" else [0.0, 1.0]
        return np.array([min(self._age / HORIZON, 1.0), *onehot], dtype=np.float32)

And step()'s timing half now calls the two new functions instead of a single hardcoded formula, while reset() picks a starting compound and the bookkeeping half switches on whichever PIT_* action was taken:

Reference snippet (a last-resort hint: the lab uses different numbers) 
        lap_time = 1.0 + toy_pace(self._compound) + toy_wear(self._compound, self._age)
        ...
        if action == PIT_A:
            self._compound, self._age = "A", 0
        elif action == PIT_B:
            self._compound, self._age = "B", 0

(reset() additionally sets self._compound = "A" alongside self._age = 1.) Run it with a policy that switches to B partway through and watch the total change: the compound trade-off that page 02's worked example priced by hand.

Stage 3 — a wear cliff, capped

Real tyres are fine for a while, then fall off a cliff, then the damage levels off. Model it in two pieces: gentle linear wear below an age threshold, and a steep but capped penalty above it. On the Pit Wall, A at age 10 is four laps past its cliff: 0.15 × 4² = 2.4 s on top of its linear wear. Only toy_wear and the COMPOUNDS data change:

Reference snippet (a last-resort hint: the lab uses different numbers) 
COMPOUNDS = {
    "A": {"pace": 0.0, "wear_rate": 0.05, "cliff_age": 4, "cliff_severity": 0.15, "cliff_cap": 4.0},
    "B": {"pace": 0.6, "wear_rate": 0.02, "cliff_age": 7, "cliff_severity": 0.08, "cliff_cap": 4.0},
}

def toy_wear(compound: str, age: int) -> float:
    """
    Piecewise wear: linear below the cliff age, a squared-and-capped
    penalty above it. The cap matters: without one, a single very old
    tyre can produce a wear number so large it swamps every other
    signal in the reward, and every other decision stops mattering.
    """
    c = COMPOUNDS[compound]
    linear = c["wear_rate"] * age
    over = max(0, age - c["cliff_age"])
    cliff = min(c["cliff_severity"] * (over ** 2), c["cliff_cap"])
    return linear + cliff

Before wiring it back in, print toy_wear("A", age) on its own for age = 1..16 and look at the shape: nearly flat, a knee at the cliff age, then level again once the cap takes over, however old the tyre gets. Only when that looks right should you rerun the full environment (with a longer HORIZON, say 16, so the cliff has room to show up in an episode).

Stage 4 — fuel burning off

A car gets faster as it burns fuel, whatever tyre is fitted. On the Pit Wall that is 0.03 s for every lap still to go: 0.57 s on lap 1, nothing on lap 20. One new function:

Reference snippet (a last-resort hint: the lab uses different numbers) 
def toy_fuel_penalty(laps_left: int) -> float:
    """Heavier car = slower lap. Burns off linearly as the race goes on."""
    FUEL_PER_LAP = 0.08     # kg-equivalent burned per lap, in toy units
    SENSITIVITY = 0.02      # seconds of penalty per unit of fuel remaining
    return (laps_left * FUEL_PER_LAP) * SENSITIVITY

And one line added to step()'s timing half:

Reference snippet (a last-resort hint: the lab uses different numbers) 
        lap_time += toy_fuel_penalty(HORIZON - self._lap)

Print toy_fuel_penalty(laps_left) for laps_left = HORIZON down to 0 before wiring it in. It should shrink in a straight line to zero at the finish, as the real project's fuel effect does on the last lap.

Stage 5 — weather, and the wrong tyre for it

A second axis, separate from tyre choice: the track. First the penalty table and its lookup:

Reference snippet (a last-resort hint: the lab uses different numbers) 
DRY, WET = 0, 1

# Penalty for running each compound in each condition. Large off-diagonal
# terms are the point: the wrong tyre for the weather should be costly
# enough that the agent has to actually track the weather, not ignore it.
WEATHER_PENALTY = {
    DRY: {"A": 0.0, "B": 0.0},
    WET: {"A": 6.0, "B": 5.5},   # both toy dry compounds are bad in the wet
}

def toy_weather_penalty(weather: int, compound: str) -> float:
    return WEATHER_PENALTY[weather][compound]

Then the observation grows by two more (a weather one-hot), reset() samples a weather value for the episode (held for the whole episode to keep the stage small; the real plan varies it lap by lap from a historical trace: self._weather = self.np_random.integers(0, 2)), and step()'s timing half gets one more added term:

Reference snippet (a last-resort hint: the lab uses different numbers) 
        lap_time += toy_weather_penalty(self._weather, self._compound)

Run one episode with self._weather forced to WET and every lap gets slower whatever compound is fitted: the mismatch penalty at work.

Stage 6 — the pit-lap ordering rule

The subtlest stage, and the easiest to get backwards. A stop happens at the end of a lap: the whole lap is driven on the old tyre, then the car peels into the pits. So that lap is timed on the old compound at its old age, and only the next lap gets the new tyre, cold, with its out-lap warm-up. On the Pit Wall, boxing on lap 14 on eight-lap-old A costs 11.18 s on the old tyre plus the 4 s stop, and lap 15 pays 1.2 s of warm-up on B.

First the warm-up function, on its own:

Reference snippet (a last-resort hint: the lab uses different numbers) 
def toy_warmup(age: int) -> float:
    """Cold-tyre penalty: full on the out-lap, half the next lap, gone after."""
    if age <= 1:
        return 1.2
    if age == 2:
        return 0.5
    return 0.0

Then the timing half of step(), complete: every term so far, all read from the state before any stop is applied.

Reference snippet (a last-resort hint: the lab uses different numbers) 
        lap_time = (1.0
                    + toy_pace(self._compound)
                    + toy_wear(self._compound, self._age)
                    + toy_fuel_penalty(HORIZON - self._lap)
                    + toy_weather_penalty(self._weather, self._compound)
                    + toy_warmup(self._age))
        if action != STAY_OUT:
            lap_time += PIT_LOSS

Only then the bookkeeping half. The stop takes effect after lap_time has been computed:

Reference snippet (a last-resort hint: the lab uses different numbers) 
        if action == PIT_A:
            self._compound, self._age = "A", 0
        elif action == PIT_B:
            self._compound, self._age = "B", 0
        self._age += 1
        self._lap += 1

Now write it the wrong way round, switching the compound before computing lap_time, and watch a pit lap's cost.

The reveal · Stage 6

The numbers sayCheaper, by a lot

Timed first, the lap is driven on the 13-lap-old A: 14.86 s, with the 4 s cliff cap, plus the stop, 18.86 s. Switched first, it is timed on a fresh B instead: 12.03 s plus the stop, 16.03 s. The stop looks 2.83 s cheaper than it is, because the bug hides the very cliff the car pitted to escape. An agent trained on it learns to leave stops late.

The bug does not always flatter the stop. On eight-lap-old A, barely past the cliff, switching first makes the pit lap 0.82 s dearer, since B's pace gap and warm-up outweigh A's wear. Either way it charges the lap to the wrong tyre. That is why the order is a class of bug, not a matter of style.

Stage 7 — a safety car nobody scripted

So far, two episodes with the same start play out the same except for the agent's choices. Now add real chance. First the sampler, on its own, outside the class:

Reference snippet (a last-resort hint: the lab uses different numbers) 
HAZARD_PER_LAP = 0.06     # chance any given green lap starts a safety car
SC_DURATION_MEAN = 3
SC_PIT_DISCOUNT = 0.4     # pitting under SC costs this fraction of the normal loss

def sample_sc_trace(horizon: int, rng: np.random.Generator) -> np.ndarray:
    """
    Independently, each green lap has a HAZARD_PER_LAP chance of starting
    a safety car that then runs for a random duration. Sampled fresh every
    call -- two episodes should very rarely have the SC on the same laps.
    """
    trace = np.zeros(horizon, dtype=bool)
    lap = 0
    while lap < horizon:
        if not trace[lap] and rng.random() < HAZARD_PER_LAP:
            duration = max(1, int(rng.normal(SC_DURATION_MEAN, 1)))
            trace[lap:lap + duration] = True
            lap += duration
        else:
            lap += 1
    return trace

Before touching the environment, call it five times with different seeds and print each trace. The safety car should land on different laps almost every time. Only then does it earn a place in reset():

Reference snippet (a last-resort hint: the lab uses different numbers) 
        self._sc_trace = sample_sc_trace(HORIZON, self.np_random)

Then step() gets one new branch at the top, before Stage 6's terms:

Reference snippet (a last-resort hint: the lab uses different numbers) 
        if self._sc_trace[self._lap - 1]:
            lap_time = 8.0   # fixed, slow flag-lap time -- no term above applies
            if action != STAY_OUT:
                lap_time += PIT_LOSS * SC_PIT_DISCOUNT
        else:
            lap_time = (1.0 + toy_pace(...) + ...)   # Stage 6's full formula
            if action != STAY_OUT:
                lap_time += PIT_LOSS

Why fresh every episode? An agent that could memorise "the safety car always comes on lap 6" would learn a lookup table, not a strategy. That is race #49 on page 01, played again with Same dice again.

Stage 8 — action masking

Not every call is legal in every situation. Build the mask rule by rule. First, "you cannot pit for the compound you are on":

Reference snippet (a last-resort hint: the lab uses different numbers) 
def toy_action_mask(compound, weather, laps_left, compounds_used) -> np.ndarray:
    mask = np.array([True, True, True])   # STAY_OUT, PIT_A, PIT_B
    if compound == "A":
        mask[PIT_A] = False
    else:
        mask[PIT_B] = False
    return mask

Then the weather rule. In this toy world, B is unsafe in the wet:

Reference snippet (a last-resort hint: the lab uses different numbers) 
    if weather == WET:
        mask[PIT_B] = False

Then "use both compounds before the flag":

Reference snippet (a last-resort hint: the lab uses different numbers) 
    if len(compounds_used) < 2 and laps_left <= 1:
        mask[STAY_OUT] = False

And a safety net, so the function never returns "nothing is legal":

Reference snippet (a last-resort hint: the lab uses different numbers) 
    if not mask.any():
        mask[STAY_OUT] = True
    return mask

Expose it as an action_masks() method, the convention from page 04 (GridWorld clamped instead; the page 04 lab is where you first write one). These are the Pit Wall's grey buttons. Run a random policy (env.action_space.sample()) with and without the mask, and count how often each ends the race never having run B. That count is what masking is for.

Stage 9 — centring the reward

The case from page 00, fixed in code. Every lap's reward is negative, so the return grows large: −231.92 at the start of this race, about −5,000 in the real one (page 03). The fix does not belong in the environment's physics. Wrap it:

Reference snippet (a last-resort hint: the lab uses different numbers) 
class RewardCentringWrapper(gym.Wrapper):
    """Subtracts a fixed constant from every step's reward. Does not change
    which policy is optimal (page 3's proof) -- only the scale of the numbers."""
    def __init__(self, env, offset: float):
        super().__init__(env)
        self.offset = offset

    def step(self, action):
        obs, reward, terminated, truncated, info = self.env.step(action)
        info["true_reward"] = reward          # keep the real number available
        return obs, reward + self.offset, terminated, truncated, info

env = RewardCentringWrapper(ToyRaceEnv(), offset=1.5) shifts every episode's return by the same amount without touching the environment's code. That is a general rule: a change to the training signal that leaves the physics alone belongs in a wrapper, not in step().

Stage 10 — what you have built

Stages 1 to 9 together are a small, complete environment with the shape of a real pit-strategy MDP: compounds trading pace for life, a capped cliff, fuel burn-off, weather, correctly ordered stops with warm-up, a fresh safety car with a cheaper stop, a mask, and an optional centring wrapper. With the lab's constants it is the Pit Wall's race. Try it: play race #49 on page 01 and open its MDP trace.
