4 · Is it Markov?

Tick every state description that is enough, on its own, to predict what happens next.
Worked solution

1. γ = 0: −2. γ = 0.5: −2 + 0.5(−1) + 0.25(−3) + 0.125(−1) + 0.0625(−4) = −3.625. γ = 1: −11.

2. Weight on the last five of twenty steps is (γ¹⁵ − γ²⁰) / (1 − γ²⁰). At γ = 0.9 that is 0.0843 / 0.8784 ≈ 9.6%. At γ = 1 all weights are equal: 5 / 20 = 25%.

3. Degradation 0.020 × 20 = 0.400. Fuel (12 × 1.600) × 0.033 = 0.634. STAY_OUT: 92.000 + 0.550 + 0.400 + 0.634 = 93.584 s. PIT_MEDIUM: 93.584 + 22.000 = 115.584 s.

4. The static maze and the tyre state are Markov. The door maze hides whether the key was collected; the last lap time alone hides the tyre's age and compound.
