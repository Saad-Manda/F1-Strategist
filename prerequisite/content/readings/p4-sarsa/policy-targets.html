The successor action is a policy choice

Suppose the next state RISK has GOOD value 6 and SLIP value −10. Current reward is zero and gamma one. Q-learning's legal greedy target is 6. If behavior actually chooses SLIP, sampled SARSA's target is −10. An expectation over epsilon-0.2 behavior instead gives 4.4. These numbers answer different questions using the same value row.

SARSA names State, Action, Reward, next State, next Action. The fifth item matters: the update uses the value of the next action selected by the behavior policy. An exploratory slip is part of that policy's continuation; replacing it with a maximum changes the algorithm.

On-policy and off-policy

On-policy learning evaluates or improves the behavior policy whose actions generate experience. With an epsilon-greedy learner, that policy includes exploration, even if a separate evaluation later uses greedy actions. Off-policy learning can target another policy, such as Q-learning's greedy continuation, while collecting exploratory transitions.

The distinction is about the target policy. It is not “online versus offline,” “random versus deterministic,” or “safe versus risky.” Both algorithms can interact online, both can use masks, and neither label guarantees a safer learned route.

Hold the policy settings fixed for a calculation

At RISK, epsilon 0.2 gives GOOD probability 0.9 and SLIP 0.1 when GOOD is uniquely greedy. At epsilon zero the behavior becomes greedy, so its expected target agrees with the legal maximum. During epsilon decay the behavior changes; there is no single fixed-epsilon value describing the whole training history.

Use successor-state legality, not the current state's mask. A chosen next action must be legal in that successor. A true terminal transition has no next action or continuation; an external truncation can still have a hypothetical continuation estimate without retaining an executable action for a new episode.
