Phase 5 · Page 01 · Table to function

From a Table Cell to a Function

The TD update never needed a table. It needed somewhere to keep a number for each state and call.

Your call · the real agent's size

Phase 4's plan keys its table on 172,800 states, with six calls each. The real plan's DQN replaces that table with a network.

How many adjustable numbers does the network have?

The table was one choice of storage

Phase 4 page 02's update, Q(s, a) ← Q(s, a) + α·δ with δ = target − Q(s, a), overwrites one cell with a nudged value. Nothing in the reasoning behind δ, or behind why many small nudges converge, depended on the storage being a table. A table was the simplest way to keep a number per (s, a).

The curse of dimensionality

The plan's table has 172,800 states, each with its own number per call, learned alone. Two states one lap of tyre age apart, everything else equal, are unrelated cells: a hundred visits to one teach the other nothing. Every dimension that needs bins multiplies the count by its number of bins, and each cell still needs about as many visits as before. Phase 6 adds a gap to each rival, and a table that was already short of visits per cell becomes hopeless. The algorithm hasn't got worse; the storage grows faster than any training budget.

The numbers say35,655 numbers

The real network's layers hold 2,176 + 16,512 numbers in the shared trunk, 8,256 + 65 in the value head and 8,256 + 390 in the advantage head: 35,655 in all (page 10 counts them). The table it replaces holds 172,800 × 6 = 1,036,800, about thirty times more.

The size isn't the main difference. No number in the network belongs to one state: every weight takes part in every state's answer.

Function approximation

Replace the lookup Q(s, a) with a parameterized function Q(s, a; θ), where θ is a vector of adjustable numbers, the network's weights. An update no longer overwrites one cell. It nudges all of θ a little, in the direction that reduces the error on the transition it has seen. Because the same weights serve every state, training on lap 27 also moves the answers for laps 26 and 28. That is generalization: one update changing predictions at states it never visited. A table can't do it, because its cells are independent by construction.

The catch

Sharing cuts both ways. An update that helps one state can hurt another the network handled well, if it treats the two as more alike than they are, or if one step moves θ too far. Pages 02 to 04 are about keeping those nudges from undoing each other: gradient descent moves θ at all, and the target network and the replay memory keep training a network online from coming apart.

What carries over unchanged

What is learned stays as Phase 4 left it. The target is still r + γ·max_a′ Q(s′, a′), and the TD error is still the signal. ε-greedy exploration carries over too, with the same straight-line decay as Phase 4 page 03, down to a floor of 0.05 and no further. Only how the number is stored and updated changes.

The champion is a function

Give the champion a state, its five numbers, and it returns three Q-values. Give it the same state again and it returns the same three. The Pit Wall's replay is a recording of those answers, made once in Python for all 1,680 states the race can reach: the network's three numbers and its greedy call in each. In evaluation the network doesn't change.

Deep diveWhy 1,680 states, and why a recording is the whole policy80 words

Laps 1 to 20, two compounds, a tyre age from 1 up to the lap number, safety car or not, both compounds used or not: 2 × (1 + 2 + … + 20) × 2 × 2 = 1,680 dry states. The greedy policy only ever asks the network about these, so a table of its answers is the policy, exact. The export script checks the recording against Python: the expected race time it gives in the browser matches Python's to 1e-9.

Evidence so farA function gives the same state the same answer every time. The champion's unplanned stops land on different laps in different races, and on lap 9 its numbers favour staying out by 5.29 s. Whatever makes those stops is not in the numbers alone.
