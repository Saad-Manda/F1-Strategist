One transition consumes a joint choice

A multi-agent state includes shared world variables and the private state of each participant. Agent i receives an observation o_i, chooses a_i, and the environment resolves the joint action a=(a_A,a_B). The transition law is P(s′|s,a_A,a_B); rewards may be separate r_A,r_B or a common team reward. Observations need not expose the full state or the other agent’s pending choice.

The one-round pack has two agents A and B, each choosing integer 0 or 1. Its team reward is 2a_A+a_B, copied to both agents. Choices (1,1) produce reward 3 for each, both true terminations, both truncations false, and an empty live-agent list. Two action submissions have caused one joint world transition; adding the two identical rewards would double the team objective.

Resolve commitments from the same pre-step state. A loop that updates A before choosing B can accidentally reveal A’s action or change B’s input. That models a different information structure even when the outer API uses dictionaries. Validate exact live-agent keys and legal values before mutating world state.

Ending and ownership are separate

At a joint boundary an agent can terminate while another remains active. Record each participant’s reward and flags against its own transition. Do not use one car’s ending flag for every replay buffer. An empty agents list is lifecycle state, not evidence that every last transition was a true task terminal.

def team_actions(actions):
    if set(actions) != {'A','B'} or any(type(v) is not int or v not in (0,1) for v in actions.values()):
        raise ValueError('exact A/B integer actions 0 or 1 required')

def joint_step(actions):
    team_actions(actions)
    reward=2*actions['A']+actions['B']
    return dict(rewards={'A':reward,'B':reward},terminations={'A':True,'B':True},truncations={'A':False,'B':False},agents=[])
