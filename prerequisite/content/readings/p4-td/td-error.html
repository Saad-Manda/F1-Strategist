Three numbers, three meanings

Suppose current Q(s,a)=2, reward is 1, legal successor values are 4 and 8, and another stored value 99 is illegal. At gamma 0.5, greedy continuation is 8. The target y is 1+0.5×8=5. The temporal-difference error δ (delta) is y−Q=5−2=3. With learning rate α (alpha) 0.25, the updated value is 2+0.25×3=2.75.

The target is a proposed value based on this transition. The error measures its disagreement with the current cell. The update moves partway toward the target. Copying y straight into Q would instead use alpha one. Multiplying reward by alpha before defining y confuses the learning rule with the task objective.

Read the equation after the arithmetic

y = r + γ continuation, δ = y−Q(s,a), and Q_new(s,a)=Q(s,a)+αδ. Equivalently, Q_new=(1−α)Q_old+αy. For alpha in [0,1] this is a weighted average of the old estimate and target, not a probability distribution over actions.

Gamma describes how future rewards count in the objective. Alpha describes how strongly this sample changes an estimate. Gamma zero still permits learning immediate reward; alpha zero freezes the cell even when the target is informative. They are not interchangeable numerical-stability settings.

A terminal transition has no continuation

If the same reward-1 transition truly terminates, y=1 and δ=−1; Q_new=1.75. The terminal reward still counts. Do not look up a terminal row's largest stored value or force its reward to zero. For a nonterminal external truncation, a successor estimate can remain relevant even though collection stops; the target remains 5 under the same assumptions.

Other table cells remain unchanged by this tabular update. If state encoding maps multiple physical states to the same key, their samples do change the same cell; that is a representation issue addressed later in the module.

Recap and self-check

With Q=2, y=5 and alpha one, what changes?

The new cell becomes 5; the target remains 5 and the error remains 3. Alpha changes the update, not this target.
