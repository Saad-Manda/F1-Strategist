Backward · three gradients and one step

Start from ∂L/∂y = 2(y − y*), then apply the chain rule as the page did.

Worked solution for the warm-up

Forward. h_pre = [1 − 3, 0.5 + 3] = [−2, 3.5]; h = [0, 3.5]; y = 0 + 0.5 × 3.5 = 1.75; L = 0.75² = 0.5625.

Backward. ∂L/∂y = 1.5. ∂L/∂W2 = 1.5 × h = [0, 5.25]. Row 0 of ∂L/∂W1 is all zero, because unit 0 is inactive and ReLU passes no gradient back through it. Row 1 is 1.5 × 0.5 × x = [0.75, 2.25].

Step. W2[1] = 0.5 − 0.525 = −0.025. The zeros are worth carrying into the code lab: a weight leaving an inactive unit gets no gradient from that example, and a unit that is inactive on every input gets none at all.
