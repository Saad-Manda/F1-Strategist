Prerequisites Hub

One entry point into every phase's prerequisite reading. Each card below is its own self-contained doc set with its own pages, glossary, and code walkthrough — this page only routes you to the right one and shows what it assumes you already know.

How these sets stack

The prerequisite sets are cumulative, not independent: each one is written assuming you've already worked through the sets earlier in the project's phase order. Phase 6's set assumes Phases 1, 3.5, 4, and 5; Phase 9's assumes everything before it except Phase 6's rival-only material is folded in via Phase 8. Read top to bottom on first pass — jump directly to a phase only once you know its listed prerequisites are already covered.

Everything you need to read and build phase-1-gym-environment.md with no prior reinforcement-learning background: the agent/environment loop, MDPs, Bellman equations, and the Gymnasium API.

3.5 DP Oracle Prerequisites 8 pages

Everything you need to build the exact optimality oracle in phase-3.5-dp-oracle.md: planning vs. learning, backward induction, stochastic transitions, and Markov chains.

Assumes: Phase 1
04 Q-Learning Prerequisites 10 pages

Everything you need to build tabular Q-learning and SARSA in phase-4-q-learning-sarsa.md: the update rule derived from the Bellman equation, epsilon-greedy exploration, and state discretization.

Assumes: Phase 1, Phase 3.5
05 DQN Prerequisites 5 pages

Everything you need to build the Dueling Double DQN agent with prioritized experience replay in phase-5-dueling-double-dqn.md: going from a table to a function approximator, target networks, and experience replay.

Assumes: Phase 1, Phase 3.5, Phase 4
06 Multi-Car Prerequisites 11 pages

Everything you need to build the multi-car environment and rule-based rivals in phase-6-multi-car-rivals.md: multi-agent MDPs, credit assignment, potential-based shaping, and overtaking/dirty-air modelling.

Assumes: Phase 1, Phase 3.5, Phase 4, Phase 5
08 Self-Play Prerequisites 11 pages

Everything you need to build the multi-agent self-play training loop in phase-8-self-play.md: non-stationarity revisited, Nash equilibria and fictitious play, checkpoint pools, and the PettingZoo API.

Assumes: Phase 1, Phase 3.5, Phase 4, Phase 5, Phase 6
09 PPO Prerequisites 12 pages

Everything you need to build the MaskablePPO training and DQN-comparison work in phase-9-ppo-sb3.md: policy gradients, actor-critic and advantage, generalized advantage estimation, and PPO's clipped objective.

Assumes: Phase 1, Phase 3.5, Phase 4, Phase 5, Phase 6, Phase 8
