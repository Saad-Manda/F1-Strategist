The label now depends on a value estimate

The network warm-up fitted fixed labels. DQN uses a sampled target y=r+γ max_(legal a′) Q(s′,a′), with zero continuation at true termination. Changing weights can change both the prediction at s and the next-state estimate at s′. Shared parameters make this feedback different from updating an independent table cell.

Suppose the current prediction is 3 and target is 5. An update raises the prediction to 3.2, but its shared next-state prediction also rises enough to move the target to 5.4. The gap grows from 2 to 2.2. These are illustrative changes, not values implied by every architecture or gradient. The same feedback can shrink a gap; online bootstrapping does not fail on every task.

Separate three sources of difficulty

Bootstrapping uses estimated continuation in the target. Function approximation couples predictions through shared parameters. Off-policy learning uses transitions collected by behavior that may explore, while the maximum values a greedy continuation. Together these mechanisms can produce instability; the finite-table convergence assumptions no longer settle the question.

Consecutive race transitions add another difficulty: a batch made only from late laps can overrepresent one part of the task. Changing data distribution and a moving label are distinct mechanisms. A target network slows changes in the label source; replay changes which retained transitions supply updates. Neither fixes missing observation information or a wrong legal mask.

Use diagnostics with a defined meaning

Monitor selected-action error, prediction and target ranges, gradient norms, parameter finiteness and frozen-policy returns. A decreasing minibatch loss can coexist with worse returns if the sampled data, target or reward proxy changes. A discontinuity just after target synchronization may be explainable; a nonfinite target or a reset-state bootstrap is a contract failure.

For a fixed detached target, a gradient step attempts to reduce the chosen regression loss. It does not prove the Bellman residual across all states decreases or that the policy improves. Distinguish “the optimizer can differentiate this loss” from “the learner converges to the right control solution.”

Recap and self-check

Does a frozen target guarantee a stationary supervised problem for the whole run?

No. Data collection and replay membership can change, and later synchronization changes the labels. It creates a slower label source, not a universal convergence proof.
