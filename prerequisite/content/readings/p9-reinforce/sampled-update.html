Build the selected-action loss

The pack’s reinforce_loss uses logits[B,A], long actions[B], returns[B] and optional boolean legal[B,A]. It validates shapes, finite values and legal sampled actions, applies the same mask before log_softmax, gathers one log probability per row and minimizes −mean(log_prob×detached_return). A [B,1] return against [B] logs would accidentally broadcast to [B,B].

Call optimizer.zero_grad(), compute the loss, backward(), optionally clip finite gradients, then optimizer.step(). Only policy parameters belong in this optimizer. Frozen observations and sampled returns must not accumulate gradients. Batch mean rescales the summed estimator; variable episode lengths can change weighting, so define the sampling unit.

A deliberate destructive witness uses uniform logits, an action-1 return 8 and learning rate 2. The first gradient makes logits [−8,8], so π_1≈.999999887. No clip objective evaluated only before that giant step can retrospectively constrain it. The later PPO lesson demonstrates why a flat incentive is not a hard parameter-step bound.

def reinforce_loss(logits, actions, returns, legal=None):
    probabilities(logits,legal)
    if actions.shape!=(len(logits),) or actions.dtype!=torch.long or returns.shape!=actions.shape or not torch.isfinite(returns).all():raise ValueError("invalid samples")
    if ((actions<0)|(actions>=logits.shape[1])).any():raise ValueError("invalid action")
    if legal is not None and not legal[torch.arange(len(logits)),actions].all():raise ValueError("illegal action")
    masked=logits if legal is None else logits.masked_fill(~legal,-torch.inf)
    logs=torch.log_softmax(masked,dim=1)[torch.arange(len(logits)),actions]
    return -(logs*returns.detach()).mean()
