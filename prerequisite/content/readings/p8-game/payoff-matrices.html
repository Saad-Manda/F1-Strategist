Specify the full game

Rows and columns are ROCK, PAPER, SCISSORS in that order. The learner payoff matrix is [[0,−1,1],[1,0,−1],[−1,1,0]]; the other player gets its negative. A policy is a nonnegative vector summing to one, not three arbitrary Q-values. Learner mixture p against opponent q scores pᵀMq=Σ_i Σ_j p_i q_j M_ij.

At p=(0,1,0), q=(.5,.25,.25), PAPER scores .5×1+.25×0+.25×(−1)=.25. At uniform p, each column has mean zero, so return is zero against any opponent mixture. Validate exact normalization rather than silently interpreting logits or raw weights as probabilities.

Remove SCISSORS and the game changes. In the ROCK/PAPER restriction PAPER dominates ROCK; PAPER/PAPER is an equilibrium. A 50/50 ROCK/PAPER opponent yields ROCK −.5 and PAPER +.5, so that mixture is not an equilibrium. A two-action example cannot demonstrate the full game’s cyclic best responses.

Use explicit orientation

Store which player owns each payoff and whether larger means better. Reversing rows and columns or subtracting the wrong reward flips the lesson. A zero-sum toy does not imply that all F1 reward designs sum to zero: shared physical cost and independent penalties can define a general-sum game.

import numpy as np

RPS = np.array([[0.,-1.,1.],[1.,0.,-1.],[-1.,1.,0.]])

def policy_vector(p):
    p = np.asarray(p,dtype=float)
    if p.shape != (3,) or not np.isfinite(p).all() or (p < 0).any() or abs(p.sum()-1) > 1e-10:
        raise ValueError('three nonnegative probabilities summing to one required')
    return p

def expected_payoff(policy, opponent):
    return float(policy_vector(policy) @ RPS @ policy_vector(opponent))
