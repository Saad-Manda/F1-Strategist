Non-Stationarity: Why Fixed Rivals Are the Right First Step

Every algorithm through Phase 5 assumes the environment holds still. This page is about the one specific way Phase 6 keeps that assumption true, and the one way a later phase won't.

The assumption everything through Phase 5 relies on

Standard RL theory — the convergence arguments behind tabular Q-learning (Phase 4) and DQN (Phase 5) alike — assumes a fixed environment: the same state, given the same action, produces transitions drawn from the same fixed distribution no matter when it's visited. Every proof and every practical guarantee this project has leaned on so far takes that for granted.

How multiple learning agents break it

The assumption holds by default in every phase through Phase 5, where there's exactly one thing in the environment that changes its behavior over time: the agent itself, as it learns. It breaks the moment more than one agent in the same environment is learning simultaneously. From the RL agent's point of view, "the environment" now includes every other agent's policy — and if those policies are themselves changing as they learn, the transition dynamics the agent is trying to learn are being pulled out from under it while it learns them.

Concretely, for a version of this project where a rival was also a learning DQN: a pit-under-safety-car move that worked well against last week's version of that rival's policy might not work at all against this week's, purely because the rival adapted — not because anything about the track, the tyres, or the weather changed. The thing the agent is trying to model as "the environment's response" is itself a moving target, which is exactly the kind of situation Phase 4 and Phase 5's convergence arguments were never built to handle.

Why Phase 6's fixed-script rivals sidestep this cleanly

RivalState follows a predetermined pit_laps / pit_compounds plan, decided before the race starts, with no learning update anywhere in it. From the agent's perspective, the rivals behave exactly like the weather trace or the safety-car arrival process it already has to react to: given, external, and — crucially — not changing in response to what the agent does. That's precisely what "stationary" means here. All of Phase 4 and Phase 5's theory keeps applying completely unmodified; the only things that got bigger going into Phase 6 are the state (page 01) and the reward (pages 02–03), not the class of environment the agent is learning in.

Why this is the sensible order, not a cop-out

Building the interaction machinery — gaps, blocking (page 05), overtaking, position-based reward (pages 02–03) — against opponents that hold still means every one of those pieces can be debugged and trusted on its own, without also having to ask "is this behaving oddly because of a bug, or because my rival just changed strategy mid-training?" Phase 8 adds the second, much harder problem — learning opponents — only once the first problem (does the interaction model itself work at all) is already solved and tested. Fixed rivals aren't a simplification taken because non-stationarity is hard to think about; they're a simplification taken so that everything else in Phase 6 has a fair chance to be verified correctly before a second source of difficulty is layered on top.
