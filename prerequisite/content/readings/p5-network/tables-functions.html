Keep the target, change the representation

Tabular Q-learning changes one stored number toward a sampled target. A neural learner predicts that number from an observation and adjustable parameters, written Q(s,a;θ). Theta, θ, stands for the collection of weights and biases. A gradient step changes those parameters to reduce prediction error. The legal-action target and ending rules from the previous module still apply; the tabular convergence theorem does not automatically carry over to a shared nonlinear function.

Sharing can help or interfere

Consider one action with prediction Q(x)=wx+b, where x is normalized tyre age. With w=2 and b=1, ages x=0.4 and 0.5 predict 1.8 and 2.0. Changing w to 3 changes both predictions to 2.2 and 2.5, even if the second observation was never sampled. That shared change is a simple example of generalization. It can help similar situations, but hurt when nearby ages straddle a tyre cliff and need different choices. Similar inputs do not guarantee similar correct outputs.

A table's different keys have independent entries. A function's outputs share parameters. An update need not change every parameter: inactive units and zero derivatives can leave some untouched. Nor does a neural function recover information missing from the observation; hidden weather history or capped ages remain modeling issues.

Count the comparison honestly

The previously defined eight key dimensions have 12×5×10×3×3×2×8×2=172,800 states and 1,036,800 entries with six actions, not the old source's 518,400 states. Adding two rival features with ten bins each multiplies entries by 100. This is Cartesian growth, not proof that tabular learning is hopeless at a particular dimension.

A network instead pays for its chosen parameters and computation. A Linear(16,128) layer has 16×128 weights and 128 biases, totaling 2176 parameters. Its width is a design choice. The model still needs enough relevant data, suitable capacity and optimization; a smaller parameter count alone does not demonstrate better return.

Recap and self-check

Does replacing a table with a network preserve Q-learning's convergence guarantee?

No. Parameter sharing, nonlinear optimization, off-policy samples and bootstrapped targets change the assumptions. The TD objective remains recognizable, but the guarantee needs a separate argument.
