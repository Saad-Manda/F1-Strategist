Stage 1 — no luck, checked against brute force

Page 02's 4-lap race: one tyre, STAY or PIT, nothing random. A dict keyed by (lap, age) is the value table; at this size an array would be overkill.

Reference snippet (a last-resort hint: the lab solves a different, larger race) 
HORIZON = 4
PIT_LOSS = 6.0

def lap_time(age: int) -> float:
    return 10.0 + 3.0 * (age - 1)

def toy_backward_induction(horizon: int):
    V = {(horizon + 1, age): 0.0 for age in range(1, horizon + 2)}
    policy = {}
    for t in range(horizon, 0, -1):
        for age in range(1, t + 1):
            stay_cost = lap_time(age) + V[(t + 1, age + 1)]
            pit_cost  = lap_time(age) + PIT_LOSS + V[(t + 1, 1)]
            if stay_cost <= pit_cost:
                V[(t, age)], policy[(t, age)] = stay_cost, "STAY"
            else:
                V[(t, age)], policy[(t, age)] = pit_cost, "PIT"
    return V, policy

Before trusting it, check it the way the real oracle will be checked: by a method that shares none of its code. Try all 24 call sequences and keep the cheapest.

Reference snippet (a last-resort hint: the lab solves a different, larger race) 
from itertools import product

def brute_force_best(horizon: int) -> float:
    best = None
    for actions in product(("STAY", "PIT"), repeat=horizon):
        age, total = 1, 0.0
        for a in actions:
            total += lap_time(age) + (PIT_LOSS if a == "PIT" else 0.0)
            age = 1 if a == "PIT" else age + 1
        best = total if best is None else min(best, total)
    return best

V, policy = toy_backward_induction(HORIZON)
assert abs(V[(1, 1)] - brute_force_best(HORIZON)) < 1e-9
print(V[(1, 1)])   # should print 52.0 -- page 2's hand-computed answer, exactly

When it prints 52.0, page 02's hand-worked answer, the code implements the recursion you checked by hand. Without the brute-force match, it is only code that runs.

Stage 2 — a risk you cannot control: the safety car

Add page 03's expectation, over a state that now includes sc_active. Only the new part is shown; the backward pass around it is unchanged.

Reference snippet (a last-resort hint: the lab solves a different, larger race) 
HAZARD = 0.2          # P(SC starts next lap | currently green)
CONTINUE_PROB = 0.5   # P(SC continues next lap | currently under SC)
SC_LAP_TIME = 20.0
SC_PIT_DISCOUNT = 0.4

def sc_transition_prob(sc_now: int) -> float:
    """P(sc_next = 1 | sc_now)."""
    return CONTINUE_PROB if sc_now else HAZARD

def toy_backward_induction_sc(horizon: int):
    V = {(horizon + 1, age, sc): 0.0
         for age in range(1, horizon + 2) for sc in (0, 1)}
    policy = {}
    for t in range(horizon, 0, -1):
        for age in range(1, t + 1):
            for sc in (0, 1):
                p_next = sc_transition_prob(sc)

                def expect(next_age):
                    return (p_next * V[(t + 1, next_age, 1)]
                            + (1 - p_next) * V[(t + 1, next_age, 0)])

                if sc:
                    this_lap, pit_extra = SC_LAP_TIME, PIT_LOSS * SC_PIT_DISCOUNT
                else:
                    this_lap, pit_extra = lap_time(age), PIT_LOSS

                stay_cost = this_lap + expect(age + 1)
                pit_cost  = this_lap + pit_extra + expect(1)
                if stay_cost <= pit_cost:
                    V[(t, age, sc)], policy[(t, age, sc)] = stay_cost, "STAY"
                else:
                    V[(t, age, sc)], policy[(t, age, sc)] = pit_cost, "PIT"
    return V, policy

On the Pit Wall's race, adding the 6% safety car takes the expected race time from 224.49 s to 231.92 s. Safety-car laps take 14 s.

Stage 3 — a call that is not always legal

Add a mandatory stop, in the spirit of the real two-compound rule: if the race reaches its last lap without one, PIT is forced. That needs one more piece of state, has_pitted, and a mask consulted before comparing calls.

Reference snippet (a last-resort hint: the lab solves a different, larger race) 
def toy_action_mask(t: int, horizon: int, has_pitted: bool) -> list[str]:
    if t == horizon and not has_pitted:
        return ["PIT"]              # STAY is illegal here
    return ["STAY", "PIT"]

Loop over toy_action_mask(t, horizon, has_pitted) in place of the fixed pair, carry has_pitted in the state key, and set it for good once a PIT is taken. Then check two things. The last lap's policy is always PIT when has_pitted is false. And the start's value is never lower than stage 2's. A mask only removes options, so it can only add time or change nothing. A mask that makes the race cheaper has a bug.

Stage 4 — a second, independent random process

Add weather from a fitted chain. Use page 04's 3 × 3 example, which is also practice at reading a matrix back out as code:

Reference snippet (a last-resort hint: the lab solves a different, larger race) 
DRY, DAMP, WET = 0, 1, 2

WEATHER_P = {
    DRY:  [0.625, 0.375, 0.000],   # from page 4's worked example
    DAMP: [0.400, 0.400, 0.200],
    WET:  [0.000, 0.500, 0.500],
}
WEATHER_PENALTY = {DRY: 0.0, DAMP: 1.5, WET: 4.0}   # added to lap_time

Weather and the safety car are treated as independent here, a simplification worth naming. The expectation becomes a double sum, each combination weighted by the product of its two chances:

Reference snippet (a last-resort hint: the lab solves a different, larger race) 
def expect_both(t, next_age, sc_now, w_now, V):
        p_sc = sc_transition_prob(sc_now)
        total = 0.0
        for sc_next, p1 in ((0, 1 - p_sc), (1, p_sc)):
            for w_next, p2 in enumerate(WEATHER_P[w_now]):
                total += p1 * p2 * V[(t + 1, next_age, sc_next, w_next)]
        return total

Use it in place of stage 3's expect(), add WEATHER_PENALTY[w] to the lap when the safety car is in, and give every state key and the terminal row a w. Solve from a DRY start and from a WET start: the WET start must cost more. Two random processes, each adding its share, is the composition Oracle B performs.

Stage 5 — check the answer before you believe it

The real test_oracle_no_absurd_exploit, in miniature. A correct solver fed a broken cost model reports an absurdly good "optimal" race, because nothing in backward induction can tell "cheap" from "cheap because of a bug". The defence is a baseline you can reason about by hand:

Reference snippet (a last-resort hint: the lab solves a different, larger race) 
def simulate_fixed_policy(pit_at_lap: int, horizon: int) -> float:
    """A simple, clearly-reasonable baseline: pit exactly once, at a fixed lap."""
    age, total = 1, 0.0
    for t in range(1, horizon + 1):
        total += lap_time(age)
        if t == pit_at_lap:
            total += PIT_LOSS
            age = 1
        else:
            age += 1
    return total

baseline = min(simulate_fixed_policy(lap, HORIZON) for lap in range(1, HORIZON + 1))
dp_value = V[(1, 1, 0, DRY)]   # stage 4's solver, dry start, no SC

assert dp_value <= baseline + 1e-9          # DP can never be beaten by a simpler plan
assert baseline - dp_value < 0.25 * baseline  # ...but shouldn't beat it by an implausible margin either

The first assertion holds by construction: the solver searches every policy, so a simpler plan cannot beat it. The second is the useful one. If the solver beats a sensible one-stop plan by a huge margin, that is not a breakthrough; a cost term has the wrong sign somewhere upstream. The capstone's report makes the stop gain 4 s and watches your solver pit on nearly every lap.

That is the whole toy oracle: a backward pass checked against brute force, an expectation over a hazard, a mask, a second random process fitted as a chain, and the check that catches a broken model. Page 06 names the piece of the real files that matches each stage.
