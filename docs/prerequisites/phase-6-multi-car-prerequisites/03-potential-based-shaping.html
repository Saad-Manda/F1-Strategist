Potential-Based Shaping: The Principled Version

Ng, Harada & Russell (1999) found the one shape a shaping bonus can take without ever being able to change what's optimal.

Ad-hoc shaping can change the answer

Nothing stops a designer from adding any extra term to a reward to make learning faster — a bonus for exploring a certain area, a penalty for a certain action. But nothing about an arbitrary extra term guarantees it leaves the optimal policy alone. A quick illustration: imagine adding a flat bonus for making any pit stop at all, meant only to encourage the agent to try pitting early in training. If that bonus is large enough, it can make pitting look attractive regardless of tyre age — the shaped optimum genuinely becomes "pit constantly," a different, worse policy than the true optimum. Ad-hoc shaping doesn't just risk slowing learning down; done carelessly, it risks teaching the wrong thing outright.

The theorem

Ng, Harada & Russell (1999) show that shaping terms of one specific form are safe. Given any function of state alone, Φ(s) — a "potential function" — define the shaping reward as the discounted difference in potential between consecutive states:

F(s, a, s') = γ·Φ(s') − Φ(s)

Add this to the base reward at every step. The claim: no matter what Φ is, the optimal policy under the shaped reward is identical to the optimal policy under the unshaped reward — only how fast that optimal policy is found changes.

Why, without the full proof

Take any policy π and check what the shaped action-value function Q'^π(s,a) works out to, using the ordinary Bellman equation with the shaped reward substituted in:

Q'^π(s,a) = E[ r + F(s,a,s') + γ·V'^π(s') ] Try the guess V'^π(s) = V^π(s) − Φ(s) (shift every value by the potential at that state) and check it's self-consistent: Q'^π(s,a) = E[ r + γ·Φ(s') − Φ(s) + γ·(V^π(s') − Φ(s')) ] = E[ r + γ·V^π(s') ] − Φ(s) (the γ·Φ(s') terms cancel) = Q^π(s,a) − Φ(s)

The guess checks out: Q'^π(s,a) = Q^π(s,a) − Φ(s), for every policy π, including the optimal one. This holds state by state, not just at the start of an episode. Since Φ(s) doesn't depend on the action a, subtracting it from every Q(s,a) at a given state shifts all of that state's action-values by the same amount — which can never change which action has the highest value there:

argmax_a Q'*(s,a) = argmax_a [ Q*(s,a) − Φ(s) ] = argmax_a Q*(s,a)

The optimal action at every single state is unchanged. This is the same "subtracting something constant across the choice being compared can't change the argmax" move Phase 5 page 08 used for reward centring — reused here in a per-state rather than per-episode form.

One hand-worked example

A toy 3-state chain: start at A, choose either a two-step route through B or a one-step direct route to the terminal state C. γ = 1. Potential: Φ(A) = 5, Φ(B) = 2, Φ(C) = 0 (terminal potential zero, a common but not required choice).

Unshaped rewards: A→B: −3 B→C: −1 A→C (direct): −10 Unshaped returns: via B: −3 + −1 = −4 direct: −10 → Optimal choice: via B (−4 beats −10 by 6) Shaping terms, F(s,s') = Φ(s') − Φ(s), since γ=1: F(A,B) = 2 − 5 = −3 F(B,C) = 0 − 2 = −2 F(A,C) = 0 − 5 = −5 Shaped rewards: A→B: −3 + −3 = −6 B→C: −1 + −2 = −3 A→C: −10 + −5 = −15 Shaped returns: via B: −6 + −3 = −9 direct: −15 → Optimal choice: via B (−9 beats −15 by 6 — same gap, same winner)

Both routes' returns shift by exactly −Φ(A) = −5 — the same constant, because Φ(C) = 0 cancels the far end of the telescoping sum and only the shared starting potential is left over. The ranking between the two options — the only thing that determines which policy is optimal — is untouched. This is the numeric face of the algebra above: shift every value at a state by the same amount, and nothing about which action looks best there can change.

The real plan's choice of Φ

The real plan's potential_shaping reward design uses Φ(s) = -position_normalized = -(position / n_cars) — "being in a better position is a better potential," so a car that moves from P4 to P2 gets a positive shaping bump exactly when it improves its standing, and by the theorem above, this can never change what the truly optimal racing policy is, only how quickly an agent finds it. Whether the plan's actual code computes this correctly is a separate question, taken up on page 06.
