Warm-up, in the page · how slowly is "slowly"?

The online network jumps once and then holds still. After every update the target network closes a fraction τ of the gap that is left. Drag τ. The readout converts updates into laps and races with the real agent's settings: one update every 4 laps, 52 laps a race.

A hard copy every 139 updates and a soft update at τ = 0.005 both close half a gap in about 139 updates. Which one makes every target jump at the same moment?
Worked solution for the warm-up

Half-life in updates: n = ln 0.5 / ln(1 − τ). At τ = 0.01, n = 68.97, so update 69; 276 laps; 5.3 races. One race (13 updates) needs τ = 1 − 0.5^(1/13) ≈ 0.052. At τ = 0.005 after 1,000 updates, 0.995¹⁰⁰⁰ ≈ 0.67% of the gap is left. The hard copy is the one that jumps.
