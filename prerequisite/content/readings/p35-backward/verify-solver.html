Make the calculation executable

The backward pass below implements the four-lap timing example. It initializes the complete terminal slice, including age horizon+1 reached after the last STAY. During lap t, only ages 1 through t are reachable from a fresh start. The comparison uses STAY on a tie.

def race_dp(horizon):
    if type(horizon) is not int or not 0 <= horizon <= 10:
        raise ValueError("horizon must be an integer from 0 to 10")
    costs = {(horizon+1, age): 0.0 for age in range(1, horizon+2)}
    policy = {}
    for lap in range(horizon, 0, -1):
        for age in range(1, lap+1):
            current = 10 + 3*(age-1)
            stay = current + costs[lap+1, age+1]
            pit = current + 6 + costs[lap+1, 1]
            action = "STAY" if stay <= pit else "PIT"
            costs[lap, age] = min(stay, pit)
            policy[lap, age] = action
    return costs, policy

def brute_race(horizon):
    from itertools import product
    best = float("inf")
    for actions in product(("STAY", "PIT"), repeat=horizon):
        age, total = 1, 0.0
        for action in actions:
            total += 10 + 3*(age-1) + (6 if action == "PIT" else 0)
            age = 1 if action == "PIT" else age+1
        best = min(best, total)
    return best

costs, policy = race_dp(4)
assert costs[1,1] == brute_race(4) == 52
assert policy[2,2] == "PIT"

Brute force explicitly simulates all 2^h action sequences; it does not call the backward recurrence. That makes disagreement informative. It is feasible here but scales exponentially. Testing both solvers only at the initial state can miss incorrect unreachable rows or tie handling, so inspect selected cells and simulate the policy too.
