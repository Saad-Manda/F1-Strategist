Glossary

Every term used across pages 1–10 — nothing beyond them. Keep this open while reading the Phase 6 plan or its eventual code.

Scope note

Terms belonging to self-play, PettingZoo, or genuinely non-stationary multi-agent learning aren't listed here because Phase 6 doesn't implement them — page 07 previews why Phase 8 needs them, not what they are. See the eventual Phase 8 prerequisites for that vocabulary.

Multi-car state extension
The three features added to Phase 1's 16-dimensional observation for Phase 6: gap_to_car_ahead, gap_to_car_behind, position_normalized. See page 1.
Race position
A car's rank among all cars in the race, computed by sorting cumulative total_time ascending. Page 5 explains why this computation alone isn't enough to make position matter strategically.
Credit-assignment problem
The difficulty of apportioning a reward that arrives many steps after the decisions that caused it back across those decisions — acute here because "final position" is known only at the very end of an episode. See page 2.
Sparse reward
A reward that's zero (or absent) on most steps and non-zero only rarely, such as final position, known only on the terminal step. Contrasted with Phase 1–5's fully dense -lap_time. See page 2.
Reward shaping
Adding an extra term to a base reward to make learning easier or faster. Can be principled (potential-based, page 3) or ad-hoc (page 2's gap_change, page 3's pit-bonus example), with very different guarantees about whether the optimal policy is preserved.
Reward hacking / proxy optimization
An agent finding the fastest way to raise a proxy reward's number, which isn't always the same as the best way to achieve the real objective the proxy stands in for — the tyre-pushing risk named for gap_change on page 2, and the general lesson behind E3 on page 6.
Potential-based shaping
A shaping term of the specific form F(s,a,s') = γ·Φ(s') − Φ(s), for any function of state alone Φ. Ng, Harada & Russell (1999) prove this form, and only this form, preserves the optimal policy exactly. See page 3.
Potential function Φ(s)
The state-only function a potential-based shaping term is built from — the real plan's choice is Φ(s) = -position_normalized. See pages 3 and 9.
Ng-Harada-Russell theorem
Cross-reference to "potential-based shaping" above — the paper's central result, worked through via a one-step Bellman-consistency check on page 3 rather than the full proof.
Dirty air
The real aerodynamic effect where a trailing car loses downforce, and pace, running close behind another. Modeled as a linear penalty from 0.5s at zero gap to 0s at a 1.5s gap. See page 4.
Following gap / DRS-style attempt gap
The distance threshold (1.0s in the real plan) within which an overtake attempt becomes possible at all. See page 4.
Probabilistic overtaking model
The sigmoid function converting a car's pace advantage over the car ahead into a probability that an attempted pass succeeds, plus a small bonus for consecutive laps spent following. See page 4.
Track position as a resource
The idea that being ahead has value in itself, beyond the time already banked to get there — only true once a blocking constraint exists; without one, position is purely a readout of accumulated time. See page 5.
Blocking constraint
The rule that a trailing car within the following gap, absent a successful overtake, is held to at best the pace of the car ahead (plus dirty air). The one addition that makes track position a real resource. See page 5.
Undercut
Pitting before a rival on comparable pace so that fresh tyres convert into track position the rival can't immediately take back, because — with a blocking constraint in place — the rival can't simply drive around a stopped or slower car. See page 5.
Overcut
The mirror strategy: staying out longer than a rival to bank track position on old tyres before eventually pitting, betting that the time lost to degradation is worth less than the position gained by staying out. Named alongside "undercut" throughout this set; the mechanism is symmetric.
Non-stationarity
The breakdown of the fixed-environment assumption underlying standard RL convergence results, once more than one agent in the environment is learning and changing its behavior over time. See page 7; full treatment deferred to the eventual Phase 8 prerequisites.
Stationary opponent / fixed-script rival
An opponent whose behavior is decided in advance and never adapts to what the learning agent does — Phase 6's RivalState, which sidesteps non-stationarity entirely by construction. See pages 1, 7 & 9.
Double-counting bug (E1, as a general pattern)
Two separate pieces of code both updating the same piece of state, each unaware the other already did. See page 6.
Dead-code overwrite (E2, as a general pattern)
A stateful, partial update to a quantity immediately followed by a from-scratch recomputation of that same quantity, where the recomputation silently wins. See page 6.
Reward/dynamics disagreement (E3, as a general pattern)
A reward that penalizes or rewards something the actual state transitions don't reflect — a reward-hacking surface, not a cosmetic inconsistency. See page 6.
