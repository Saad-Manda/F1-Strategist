Two routes to the same decision

At state A, DIRECT ends for reward 3; VIA gives 1 and reaches B, where FINISH gives 4. With two decisions remaining and gamma one, VIA is best: total 5. Foundations calculated this from a supplied model. A planner can ask what any legal action would do, including actions it has never executed. A learner given only sampled transitions must discover or estimate those consequences from experience.

Planning does not mean choosing by immediate reward: DIRECT's 3 beats VIA's immediate 1, but loses after continuation. Learning does not mean randomness: even a deterministic world may have an unknown model. The distinction concerns available information, not whether the final policy is deterministic or whether the environment contains noise.

Specify the model's answer

A model query returns successors, rewards or costs, probabilities and ending information. For the A/B world the entire nonterminal model is small enough to write:

MODEL = {
    "A": {"DIRECT": ("T", 3.0), "VIA": ("B", 1.0)},
    "B": {"FINISH": ("T", 4.0)},
}

T is terminal; it has zero continuation and no decisions. A table can represent this model exactly because its states and actions are finite and every rule is given. A racing simulator with continuous temperature and history-dependent weather does not automatically become such a finite model just because its Python code is accessible. Decide what state, resolution and transition law the planner is actually solving.

What an exact answer establishes

“Exact” means exact for the specified mathematical model, up to numerical computation. A missing cost, an incorrect pit transition or a coarse state can still produce an exactly solved wrong problem. The answer is useful as a reference: a sampled learner on the same task should be evaluated against this optimum, with comparable information and constraints.

If the planner sees future events that the learner cannot see, its reference measures an information advantage too. If it uses different weather probabilities, its answer concerns a different task. Keep both distinctions visible before interpreting a performance gap as failure to learn.

Recap and self-check

Planning uses a model to calculate consequences; learning uses experience to estimate useful behavior. Both can optimize expected return, and both depend on a correct task definition.

Does calling env.step twice on the live environment give the two hypothetical branches from A?

No. The first call changes state. A hypothetical model query must evaluate each action from the same original state without advancing the live world or its random stream.
