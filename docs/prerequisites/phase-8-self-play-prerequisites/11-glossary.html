Glossary

Every term used across pages 1–10 — nothing beyond them. Keep this open while reading the Phase 8 plan or its eventual code.

Scope note

Terms belonging to PPO, actor-critic methods, or Stable-Baselines3 aren't listed here because Phase 8 doesn't use them — those belong to the eventual Phase 9 prerequisites.

Non-stationarity (multi-agent case)
The breakdown of the fixed-environment assumption once more than one agent in the world is learning and changing its own behavior, so that transitions describing an earlier version of the game no longer describe the current one. See page 1.
Independent learners
Each agent has its own separate value function and learns only from its own experience, with no shared network or communication between agents. The paradigm the real plan uses. See page 1.
Parameter sharing
All agents use one shared network trained on everyone's combined experience — faster learning, but assumes symmetric agent roles. See page 1.
Centralized-training, decentralized-execution (CTDE)
A shared value function (often a centralized critic) sees every agent's joint state during training, while each agent still acts on its own local observation at execution time. The more powerful, more complex alternative not used here. See page 1.
Nash equilibrium
A pair of strategies where neither player can improve their own return by unilaterally switching, holding the other player's strategy fixed — the natural notion of "solved" for a two-player game. See page 2.
Best response
The strategy that maximizes a player's own return given a fixed assumption about what the other player is doing. See page 2.
Fictitious self-play
Repeatedly best-responding to the running average of the opponent's past strategies rather than their single latest strategy; provably converges to a Nash equilibrium under broad conditions. The theoretical backbone the checkpoint pool approximates. See page 2.
Population-based training
Training against a diverse population of policies rather than one running average — AlphaStar's large-scale descendant of fictitious self-play, and the direct motivation for keeping a 50-checkpoint pool. See page 2.
Checkpoint pool
A stored collection of past policy snapshots sampled from during training, standing in for fictitious self-play's running average since neural network weights can't meaningfully be averaged the way a mixed strategy can. See page 3.
Recency-biased sampling
The real plan's sampling rule: 70% chance of sampling from the most recent 20% of the pool, 30% chance from the older 80% — roughly a 9:1 per-checkpoint weighting of recent versus old. See page 3.
Self-play evaluation trap
The fact that a rising self-play training reward curve only proves progress relative to one's own recent history, not skill against a genuinely different opponent — the reason the real plan's Definition of Done checks the learner outside the self-play loop. See page 3.
PettingZoo
The library providing standard multi-agent environment APIs (AEC and Parallel) that F1PettingZooEnv is built on. See page 4.
AEC (Agent Environment Cycle) API
Agents act strictly one at a time in a cycle, each seeing the state left by the previous agent's action — the natural fit for turn-based games. Not used by this project. See page 4.
Parallel API
All agents submit actions simultaneously each timestep, with no agent seeing another's action before committing to its own. The API F1 strategy actually needs. See page 4.
possible_agents / per-agent dict convention
PettingZoo's convention of keying observations, actions, rewards, and spaces by agent id in a dict rather than a single shared value. See page 4.
Degenerate deterministic policy (as a general pattern)
A greedy policy over an untrained or randomly initialized function, which is not noisy or varied but a fixed, repeatable answer — easy to mistake for a random baseline. See page 5.
Blocking constraint / track position as a resource
The rule that a trailing car within a following gap, absent a successful overtake, is held to at best the pace of the car ahead — the one addition to Phase 6's dynamics that makes track position, and therefore pit-timing relative to a rival, matter at all. See page 6 (full derivation: Phase 6 page 5).
Undercut
Pitting before a rival on comparable pace so fresh tyres convert into track position the rival can't immediately take back — unreachable as a learned behavior until the blocking constraint above exists. See page 6.
Overcut
The mirror strategy: staying out longer than a rival to bank track position on older tyres before eventually pitting. See page 6.
Permutation test / null baseline
Comparing an observed statistic against the same statistic recomputed on data with the tested-for relationship deliberately destroyed (here, by shuffling the pairing between an agent's pit laps and a rival's), to check whether an observed pattern could plausibly have arisen by chance. See page 7.
