# RL lab exercise packs

Open `index.html` in this folder through the static website to browse all 25 labs.
Each lab provides a JavaScript experiment and a downloadable Python exercise ZIP.
Extract the ZIP and follow its own README to implement and run checks locally.

Requested hints and reference solutions are optional help. Browser progress can be
exported/imported; Python runs on your machine. No account or backend is required.

Author documentation and tooling live outside the published site in the learning
project's `docs/` and `scripts/` directories.
