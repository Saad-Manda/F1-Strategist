Stop collecting without erasing genuine continuation

The browser pack's witness is Q=2, reward 1, successors [4,8,99], mask [True,True,False], alpha 0.25 and gamma 0.5. Ongoing and externally truncated transitions both yield target 5, error 3, value 2.75. True termination yields target 1, error −1 and value 1.75. When both flags are true, termination removes continuation.

Bootstrapping on truncation uses the final observation of the unfinished transition. An automatically reset environment may return a new episode's initial observation separately; never bootstrap from that reset state. A rollout batch cutoff similarly need not be a task terminal.

Validate the row you will actually use

def legal_indices(values, legal):
    import math
    if len(values) != len(legal) or any(not math.isfinite(v) for v in values):
        raise ValueError("finite values and matching mask required")
    indices = [i for i, allowed in enumerate(legal) if allowed]
    if not indices:
        raise ValueError("at least one legal action required")
    return indices

def update(q, reward, next_values, legal, alpha, gamma,
           terminated, truncated=False):
    import math
    validate_distribution([alpha,1-alpha])
    validate_distribution([gamma,1-gamma])
    if not math.isfinite(q) or not math.isfinite(reward):
        raise ValueError("finite q/reward required")
    continuation = 0 if terminated else max(next_values[i]
                                           for i in legal_indices(next_values,legal))
    target = reward + gamma*continuation
    error = target-q
    return dict(target=target, error=error, value=q+alpha*error)

This matches the unchanged pack: terminal rows can have empty successor arrays because the function never selects from them. A nonterminal empty legal set is an error. Even gamma zero does not make an invalid nonterminal row valid under this contract. The truncated argument deliberately does not zero continuation; it records a collection boundary.

Masks have two separate jobs

Use today's mask while choosing today's action. Use the successor's mask in the target. Filtering illegal 99 only from action selection leaves an incorrect target if the maximum still reads it. Multiplying illegal Q-values by zero is also wrong for negative rewards: zero can outrank every legal negative value. Filter legal indices or use a carefully handled negative-infinity maximum mask.

Recap and self-check

A terminal transition gives −7 with no legal successor. Should max([]) be evaluated?

No. The target is −7 directly. An empty successor set is acceptable here because the task truly ended, not because the implementation invents an action.
