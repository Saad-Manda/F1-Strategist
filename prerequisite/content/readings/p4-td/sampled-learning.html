Replace a known expectation with experience

The planner knew every possible successor and its probability. A sampled learner instead receives (state, action, reward, next state, terminated, truncated) from one interaction. It stores estimated action values Q(s,a) in a table and changes the visited cell using that evidence. It need not know the whole transition model.

For an uncertain action, suppose reward 2 and successor estimate 4 occur with probability 0.8, while reward −1 and successor estimate 1 occur with probability 0.2. At gamma 0.5, the model's expected one-step target is 3.1. A sampled target is either 4 or −0.5. Repeated samples supply evidence about the expectation; a single lucky target is not the true action value.

Bootstrapping means using an estimate

A complete return waits for future rewards. A temporal-difference target uses immediate reward plus a successor estimate, so the estimate can improve before a whole episode completes. That reliance on another estimate is called bootstrapping. If the successor table is wrong, today's target can be wrong too.

This is not circular reasoning without evidence: sampled rewards anchor updates, and future estimates can improve as relevant transitions are visited. But correction is not automatic in an unvisited state, an aliased representation or a changing task. A table of plausible numbers is not evidence of successful learning.

Separate the target policy from data collection

Q-learning uses the largest legal successor estimate, targeting greedy continuation. SARSA later uses the action sampled by the behavior policy. Both may collect exploratory experience, but their targets answer different policy questions. Keep this distinction separate from whether the environment itself is random.

In an exactly known tiny world you can compute a reference by planning and compare sampled updates against it. In a large project, lack of a full model is a reason to learn from samples, not a reason to abandon independent small witnesses or physical-unit checks.

Recap and self-check

Must an observed target of 4 equal the uncertain action's expected value 3.1?

No. It is one sampled target based on a successor estimate. Its conditional expectation can match the current model backup without being the exact optimal value.
